「確認済」は表に書いた範囲だけの確認。「部分」は実装の一部が存在。「未実装」は当該の記述に対応する処理がない。「要整理」は現在の契約と旧記述の対応が未決定。「未検証」は根拠が足りない。全体の完成率は算出しない。
