# 洞窟の修正

依頼者が農村・町・世界の方向性を採用した。今回はそれらの配置と比較画像を変更せず、洞窟だけを修正した。仲間の再配色は実画面での判断を待ち、変更していない。

`cave-natural-compare.png` の左が目標、右が新しい32pxタイル層から描画した洞窟。壁の厚みは64px、すなわち2タイル以上。内側32pxは明るい側面、外側32pxは暗い上面とし、外周と内柱2か所へ同じ規則を適用した。画面下の入口は開放している。

壁は距離帯方式で自動接続する。床の輪郭から八近傍へ64pxの帯を作り、丸石の上面・側面を割り当て、32pxセルへ分割する。変換規則は台帳の `autotile_rule` と配置JSONの `terrain_rules` に保存した。今回必要になった輪郭のセルをアトラスへ保存しており、47形の一覧から選ぶ従来方式とは異なる。別の輪郭では同じ規則で必要セルを再生成する。

湖3か所は不規則な曲線で作り、縁に7pxの岩岸を付けた。各湖の塗られた面積は外接四角形の約68%で、四角い塗りつぶしにはなっていない。床と水は新しい低密度の模様を使い、模様の参照位置もずらして反復を抑えた。原画のパネル境界線は切り落とし、素材に残していない。

`floor-mask.png` と壁・湖のマスク、`cave-revision-checks.json` が検査の記録。`tools/check_owner_monsters.py` が壁全体を再計算して一致を調べ、側面が上面より明るいことも実画素から確認する。

生成原画と指示は `assets/source_records/cave-wall-revision.json`。参考JPEGは比較と絵柄の参照専用で、画素の切り出しはしていない。配色は既存のnatural64色以内。変更したのは素材と静止配置だけで、本番のワールドや画面処理には接続していない。
