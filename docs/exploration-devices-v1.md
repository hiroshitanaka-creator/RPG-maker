# 既存ダンジョンの仕掛け・近道・補給箱

2026年9月19日。既存5ダンジョンへ、装着技を使う設備を各1箇所、対応する補給箱を各1箇所追加した。職業を変えて覚えた技を、限られた装着枠に持ち越す選択を探索でも使う。

地点、設備名、必要技、報酬は実装上の調整案。確定条件のGodot 4.7.2-stable、3〜4人、20職、最大4枠は維持する。配置は`data/exploration_v1.json`で管理する。

## 配置と操作

| ダンジョン | 設備の位置 | 使用できる技のいずれか | 消費MP | 補給箱の位置 | 回復薬 |
|---|---|---|---|---|---:|
| 旧水路 | 巻き上げ機 (10,8) | 堅守／強打 | 3／3 | (15,8) | 2 |
| 地下回廊 | 固着扉 (15,6) | 強打／火球 | 3／4 | (18,6) | 2 |
| 旧教習所 | 仕切り (14,10) | 先制斬り／氷弾 | 3／3 | (14,13) | 3 |
| 記録坑道 | 感応扉 (17,7) | 響きの波／光輪 | 4／6 | (20,7) | 3 |
| 分け水門 | 保守橋 (20,9) | 堅守／氷弾 | 3／3 | (20,6) | 3 |

座標はマップ左上を原点にしたマス位置。探索画面では設備を青い枠、補給箱を緑の箱、利用済みを灰色で示す。そこへ歩き、Enter・E・「調べる」から担当者と技を選ぶ。条件不足ならその画面から編成へ入り、装着を変更して戻れる。

操作時に担当者の生存、技の習得と現在の装着、残りMPを確認する。条件不足や取消では状態を変更しない。成功すると担当者のMPだけを消費し、通路と補給箱を開く。設備を繰り返し調べても再消費しない。

選んだ技の消費MPは戦闘データを参照する。全候補は人間職でも習得できる既存の共通技であり、魔物職に転職した後でも、習得・装着を保っていれば使用できる。現在の共通技の侵蝕ルールに従い、使用による侵蝕は加算しない。魔物専用技を侵蝕なしで使う経路は追加していない。

開通後は水路3マス、ほか4箇所各1マスが通行可能になる。どの設備も既存の迂回路より短い通路になる。未開通でも従来の本編経路は通れる。補給箱は対応する設備を操作すると解錠され、記載の薬を一度だけ受け取れる。本編の戦闘・8件の回収・2本の連鎖を飛ばすことはない。

## 保存

`progress_flags`へ`exploration_<地点ID>`を追加する。設備5・補給箱5の最大10フラグで、開通済みと受取済みを区別する。新しいフラグがない従来の保存は未利用として扱い、保存形式の番号は1のまま。

操作は保存状態のコピーへ適用してから、MP、フラグ、世界の位置を検査して一括確定する。受取後に保存・ロードしても報酬を再取得できない。開通した通路の中から町へ帰還した場合、帰還位置にも開通状態を適用して読み込む。開通フラグがない通路内の位置、未知の設備ID、解錠前なのに受取済みの保存は拒否する。

JSONの座標は整数へ統一する。初回の追加検査で、JSON由来の小数型の配列と移動側の整数配列が一致せず、同じ場所で調べても設備を認識しない失敗を確認した。読込側を修正し、期待値を変えずに再検査した。

## 検証

`tools/check_exploration_devices.gd`を実装前に実行し、未接続による終了コード1を確認した。検査内容は次のとおり。

- 新規開始から通常の移動・会話・2戦を経て強打を習得する。装着し、水路の設備を開き、補給箱を受け取る。
- 条件画面を開く・取り消す・条件を参照する操作で状態を変えない。
- 未装着、直前に取り外した技、MP不足、戦闘不能、戦闘中、地点から離れている場合の操作を拒否する。
- 5設備それぞれに用意した両方の技で開通し、技ごとのMPが消費される。開通前後の歩行経路を比較して距離が短くなることを確認する。
- 開通した通路の中で帰還・保存し、ロード後に元の位置へ戻る。受取後の保存からも二重に補給を得られない。
- 3人編成の各地点と、魔物職で共通技を持ち越す条件は、有効な保存状態を用意して検査する。この部分を新規開始からの育成とは扱わない。

```powershell
. .\tools\prepare_scope_env.ps1
godot --headless --path . --script res://tools/check_exploration_devices.gd
python tools/run_locked_checks.py
python tools/check_frozen_files.py
python tools/validate_assets.py --strict
```

Godotの実描画でも通常の移動から操作し、[技の選択画面](verification/screens/exploration_options.png)、[受取済みの箱](verification/screens/exploration_collected.png)、[開通した水路](verification/screens/exploration_shortcut.png)を保存・目視した。描画検査の標準エラーは空で、`EXPLORATION_PASS`まで到達した。CIにも追加検査を組み込む。

## 残る作業

5〜6時間の内容量と実測、人間による探索の分かりやすさ・報酬・難易度の確認は未達。この追加だけで目標時間を満たしたとはしない。設備は操作地点を示す図形で表示し、新しい専用画像は生成していない。人物の歩行・戦闘・魔物化外見について前回列挙した未接続は残る。
