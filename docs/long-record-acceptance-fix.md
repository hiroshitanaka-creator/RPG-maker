# 長編が未完成の記録を時間受入候補から除外

2026年9月20日。現在の正式目標は約60時間。以下は記録の判定処理の修正で、人間の試遊を実施した記録ではない。

## 確認した問題

長編を本番でまだ有効にしていない間、実ゲームは `long_campaign_required:false` を記録していた。ゲーム内レポートとPython集計はこの値を見て長編完走の確認を省いていたため、旧内容の完走と時間条件だけで60時間の候補を作れる状態だった。必須欄が欠落した時も同じ結果になった。

ゲーム内レポートには、同じ地点を5回並べても5地点の完走として扱う問題と、長編完了の値 `1` を真とみなす問題もあった。

## 変更

- 現在の記録では長編を必須として示し、実装中の有効／無効を受入条件へ転用しない。
- ゲームとPythonの両方で、長編完了が真偽値の `true` であることを必須にする。必須欄をfalseにしたり削ったりしても未完走を受け入れない。
- 既存5地点も、配列に異なる正しいIDが5件あることを確認する。重複・余分な件数・誤った型を拒否する。
- 時間帯専用の合成fixtureには、長編完了という前提を明示した。完走の判定は別の追加ケースで検査する。時間の境界値と期待される成否は変更していない。

## 検査

| コマンド | 修正前 | 修正後 |
|---|---|---|
| `godot --headless --path . --script res://tools/check_long_record.gd` | exit 1、未完成の実ゲーム文脈・必須欄false／欠落・地点重複・型誤り等6件 | PASS |
| `python tools/check_long_record_summary.py` | exit 1、必須欄false／欠落の2件 | PASS。余分な地点・辞書型・重複・本編完了の型も拒否 |
| `godot --headless --path . --script res://tools/check_duration_target.gd` | 既存の時間境界検査 | PASS。3,239／3,240／3,600／3,960／3,961分と、旧目標・自動操作の除外 |
| `python tools/check_duration_summary.py` | 既存の時間境界検査 | PASS。旧330分も含めて照合 |

実ゲームの新規状態から取得した文脈について、他の時間・旧内容条件だけを満たしても長編未完走なら候補にならないことを確認した。完走済みという合成入力が候補になっても、正式受入は `UNREVIEWED`、人間が実際に操作したことの検証はfalseのままである。

現在の32話を、80話完走や60時間の内容量・実測として扱わない。人間の実測・主観はNOT_RUNのまま保持する。
