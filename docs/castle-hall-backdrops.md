# 城の部屋のつながりの作り直しと、一枚絵の背景（大広間・謁見の間・灯台の見張り部屋）

2026年9月30日の依頼。手順は `docs/port-inn-backdrop.md` に従った（`docs/interior-backdrops.md` は main に存在しなかったため参照できていない）。

## 部屋のつながり

```
城の外 → 中庭(1) → 大広間(11) → 奥の中央の扉 → 謁見の間(2)
                              → 奥の左の扉   → 宝物庫(3)
                              → 奥の右の扉   → 書庫(10)
```

- 大広間は部屋番号11（末尾に追加）。既存の部屋番号は変えていない。謁見の間は部屋番号2のまま。王の謁見で転職・技の装着が解放される処理（`GameSession.finish_first_region_audience`）は部屋2・王のイベントに紐づくので、そのまま動く。
- 謁見の間は下の扉1つ（大広間と接続）。左右の扉はなくした。宝物庫・書庫は下の扉1つのままで、接続先を大広間に変えた。
- 中庭の上の扉(16,10)は大広間の下の両開き扉へ。両開き扉と謁見の間の扉は2マス幅なので、扉のセルを2つずつ持つ。
- 台詞を2か所変えた（つながりが変わり、元の台詞が事実と合わなくなったため）：中庭の兵士「正面の扉が大広間です。奥の中央の扉が謁見の間です。」、謁見の間の右の兵士「宝物庫と書庫へは、大広間の奥の左右の扉からどうぞ。」。人物・役・ほかの台詞は変えていない。
- 港町の灯台の見張り部屋は、扉のマスが(8,10)/(8,11)から(9,8)/(9,10)へ移った。灯台守は(10,7)から(8,4)へ。

### 切った・足した部分（すべて外周の暗色だけ）

- 謁見の間：左6px・下0.5pxを切り、上へ18pxの暗色を足した（扉の下端をマス目へ揃えるため）。
- 灯台：左右4pxずつを切った。
- 大広間：右5pxを暗色で埋め、左へ2px寄せた。

### 通行地図

「人物の足元（マスの下半分）が床に乗るマスだけ歩ける」規則で手書きした。確認図は `docs/verification/castle-hall-backdrops/*-collision-overlay.png`（緑＝歩ける、赤＝通れない、黄＝扉、青＝人物）。

- 大広間：奥の壁の正面の面（扉と旗の段）は歩けない。扉のマス(5,2)(8,2)(9,2)(12,2)は壁の前に立って入る。柱の外側の細い通路は入口がないため歩けない扱い。
- 謁見の間：王は玉座の壇の前(12,5)、側近は壇の脇(14,5)、兵士は入口の左右(10,12)(13,12)。絨毯の上(12,6)から王へ話しかける。柱の間の7行目は通り抜けられる。
- 灯台：望遠鏡・机・椅子・樽・窓の壁は歩けない。

## 以前の保存への影響

読み込み時に立ち位置を安全な場所へ置き直す処理はない（`FirstRegion.valid` は歩けないマスの保存を不正として拒否する）。次の保存は読み込めなくなる。

- 謁見の間（部屋2）で保存した保存：新しい部屋の歩けるマス以外の全て。旧部屋は32×22だったため、旧扉(16,20)・左右の扉の近くなど大半が該当する。
- 灯台の見張り部屋（部屋8）で保存した保存：新しい歩けるマス以外の全て。旧入口(8,10)も歩けない。
- 中庭・宝物庫・書庫・城下町・ほかの部屋の保存は影響を受けない。

置き直し処理の追加は、依頼になかったので行っていない。
