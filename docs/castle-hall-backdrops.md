# 城の部屋のつながりの作り直しと、一枚絵の背景（大広間・謁見の間・灯台の見張り部屋）

2026年9月30日の依頼。手順は `docs/port-inn-backdrop.md` と `docs/interior-backdrops.md`（建物の中19部屋、PR #5）に従った。最新の main（PR #5 取り込み済み）の上に作り直してある。中庭・宝物庫・書庫を含む19部屋の一枚絵の背景は PR #5 のまま変えていない。

## 部屋のつながり

```
城の外 → 中庭(1) → 大広間(11) → 奥の中央の扉 → 謁見の間(2)
                              → 奥の左の扉   → 宝物庫(3)
                              → 奥の右の扉   → 書庫(10)
```

- 大広間は部屋番号11（末尾に追加）。既存の部屋番号は変えていない。謁見の間は部屋番号2のまま。王の謁見で転職・技の装着が解放される処理（`GameSession.finish_first_region_audience`）は部屋2・王のイベントに紐づくので、そのまま動く。
- 謁見の間は下の扉1つ（大広間と接続）。左右の扉はなくした。宝物庫・書庫は下の扉1つのままで、接続先を大広間に変えた。
- 中庭（PR #5 で16×12マスの背景）の上の扉(8,1)は大広間の下の両開き扉(8,9)(9,9)へ。中庭側の着地は(8,2)、大広間側の着地は(8,8)。両開き扉と謁見の間の扉は2マス幅なので、扉のセルを2つずつ持つ。
- 台詞を2か所変えた（つながりが変わり、元の台詞が事実と合わなくなったため）：中庭の兵士「正面の扉が大広間です。奥の中央の扉が謁見の間です。」、謁見の間の右の兵士「宝物庫と書庫へは、大広間の奥の左右の扉からどうぞ。」。人物・役・ほかの台詞は変えていない。
- 港町の灯台の見張り部屋は、扉のマスが(8,10)/(8,11)から(9,8)/(9,10)へ移った。灯台守は(10,7)から(8,4)へ。

## 以前の保存の置き直し（共通の仕組み）

部屋の作りを変えたあとも以前の保存を読めるよう、共通の仕組みを加えた。

- `FirstRegion.relocate_unwalkable(saved)`（`scripts/world/first_region.gd`）：保存の立ち位置が、その部屋の歩けないマス（壁・家具・人物のマス・部屋の外）なら、部屋の入口の扉の前（`FirstRegion.entrance_landing`）へ置き直す。
  - 入口の扉の前は、町・洞窟・塔・港町の入口（`*_spawn`）を先に、なければ扉・階段の接続（`doors` `castle_doors` `tower_doors` `port_doors` `stairs_down` `stairs_up`）で「その部屋へ入る」着地マス。
  - 部屋がない保存、世界マップ・船の保存、位置が壊れた保存、入口が歩けない部屋の保存は置き直さない（従来どおり読み込みを拒否）。
- `GameSession.load_game` が保存の検査の前に呼ぶ。置き直したら `GameSession.position_relocated` が true になる。歩ける位置の保存は変えない。部屋を変える処理はなく、`entry_lock` は空にする。
- 今後、部屋の作りを変えたときにも、そのまま使える（部屋ごとの個別処理はない）。

確認は `tools/check_saved_position_relocation.gd`（CIに追加）。最初の地方として保存できる5か所の全31部屋で、入口の着地マスが定義され歩けること、部屋の外の座標が入口へ戻ること、歩ける位置は動かないことを確かめ、実際の保存（型情報つき）の読み込みで、謁見の間（壁・旧扉の位置・王のマス）、宝物庫、カイナの家を置き直し、歩ける位置は置き直さず、置き直した保存を保存し直しても再度置き直さず、存在しない部屋の保存は拒否して現在の状態を壊さないことを確かめる。置き直しを無効にすると検査が失敗することも確認した。

## 作り直しの手順（再生成）

`tools/build_castle_town.py` は、城全体を最初から生成する。大広間（部屋11）と新しい扉のつながり（謁見の間は下の扉だけ、宝物庫・書庫は大広間から）を生成するよう更新した。ただし絵と通行地図は、次の順で背景の変換を重ねて作る。

1. `python tools/build_castle_town.py`
2. `python tools/build_interior_backdrops.py --town castle`（PR #5：中庭・宝物庫・書庫などの背景）
3. `python tools/build_castle_hall_backdrops.py`（この文書：大広間・謁見の間・灯台の背景と、大広間まわりの扉の最終形）

この順で再生成しても、`world/*.json` と `assets/registry.json` の内容は同じになる（確認済み。城の場所の並び順だけが変わる）。

## 旧スプリントの検査

`tools/check_castle_town_polish.py`（2026年9月28日の城下町の仕上げ用）は、検査の対象を作業ツリーではなくそのスプリントの最後のコミット `0ba8d85` に固定した。比較の相手（07ac451・20fdaab）と、合否の条件は変えていない。後のスプリントで部屋が変わっても失敗しない。
