# スプリント5・最初の区切り：城下町と城

2026年9月28日。依頼者が12職の歩行素材を採用し、スプリント3を完了した。魔物化原画を作り直しているため、実施順をスプリント5→4へ変更した。今回は城下町と城を制作し、ここで確認画像を報告して止まる。

## 制作範囲

- 関所の北に城下町の入口を追加。入口へ歩くと町へ入り、南門から出ると入口の一歩手前へ外向きに戻る。
- 城下町の広場、住人8人、宿・道具屋・武器屋・防具屋の建物・祠・民家を配置。城は中庭・謁見の間・宝物庫・書庫を歩いて行き来できる。
- 王との会話を最後まで送ると、基本職への転職と技の装着を解放し、城北の森への許可を記録する。上級職・魔物職は後の節目まで解放しない。
- 宿は既存の回復、道具屋・武器屋は既存の購入処理へ接続する。宝物庫の補給箱は一度だけ回復薬3個を受け取れる。
- 祠の中では既存の魔物化解除を使える。現在の進行では魔物職自体は未解放。解除の仕組みは既存のまま、世界マップ型では利用場所を祠の室内へ合わせる。
- 石畳を地面の層に分類し、人物より下へ描く。建物・柱など高さのある物は足元順に描く。
- 城内から道具の世界地図を開いたときは、城下町の入口が現在地になる。

## 未決事項と後続の区切り

城下町と城の正式名は依頼者へ確認中。決定までは「第1地方の城下町（仮）」「第1地方の城（仮）」と表示する。防具屋には外観・内装・店員の会話を用意したが、防具の購入・装備は既存ゲームに仕組みがないため、今回の扱いを依頼者へ確認中。購入や能力値への反映が完成したとは扱わない。

今回記録した北の森への許可は、森の塔の区切りで実際の森・塔の経路へ接続する。カイナの家の床と家具、関所を含む世界全体の水際、森の塔と保存済みスイナ加入会話、港町、転移呪文・船は、スプリント5の後続の区切りに残す。

## 原画と素材

目標は付録BのIMG_0997（城下町）、IMG_1010（城内）。`docs/reference/visual-targets/first-castle-town.png`・`first-castle-hall.png` にバイト一致の複製を保存し、確認画像フォルダの `reference-hashes.json` にSHA-256を記録した。目標画像をゲーム背景として貼り付けてはいない。

人物はIMG_1030・1031の王・側近・兵士・商人を使用。IMG_0994〜0996も確認し、今回必要な役に対応する小さい版を作画の基準とした。組み込みimagegenで歩行4方向×3コマを生成し、32×48・16色・二値透過・接地行47へ変換した。城内用に玉座・旗・燭台・本棚・柱、床・壁・敷物も生成し、既存の自然色パレットから64色以内へ変換した。

生成原画4枚：`assets/_incoming/castle-town-2026-09-28/`。生成指示全文と原画ハッシュは `assets/source_records/castle-town-generation.json`、切り出し・使用色・出力ハッシュは `castle-town-conversion.json`。原本は変更していない。

本番配置は `tools/build_castle_town.py` で生成し、`world/first_region.json`・`world/interiors.json`・`world/first_region_visuals.json` へ記録する。既存の村・洞窟の2拠点、描画8マップ、関所や通行証を含む従来の定義値は保持する。

## 確認と再実行

確認画像は `docs/verification/sprint5-castle-town/`。`town-comparison.png`・`hall-comparison.png` は目標と本番配置の比較、`runtime/` は新規開始から通常入力で到達した実ゲーム画面。

`tools/capture_castle_town.gd` は保護済みR-07を変更せず継承し、同じ通常入力で関所まで通過した後、城下町・城への移動、会話による解放、転職、保存復元、施設、退出を追加確認する。位置・通行証・進行フラグは検査から書き込まない。撮影では本番描画に人物の不透明画素が90%以上見えることも確かめる。保護された14項目・上限・禁止事項は変更しない。
