# 統合機構の実装契約と検証範囲

2026年9月23日。依頼者の「新機構の実装・実行検証」に基づく。差分表D01〜D32の推奨案を基準に進める。以下の空欄を埋める数値・配置は暫定設計値。人間の面白さと約60時間の実測はNOT_RUNとして分離する。

## 維持と採用範囲

20職・30敵・6章・80話・既存回収連鎖・3〜4人・2→3枠と魔物化＋1を維持する。通常防御の先行処理、基礎ダメージ式の切上げと最低1、JP到達でのマスター、保護ファイルを維持する。強制暴走AI、万能職、外部メモリ召喚、クリティカル連鎖覚醒、メタ通貨、恒久喪失奥義は追加しない。職別行動をマスター必須条件にはしない。

観察、専心、導電、通常／過負荷増幅、偏向防御、護衛、封緘、局所フィールド、4連撃、二刀流、上限付き反撃とMP還元、予告・解除可能な残留効果、EXP、得意MP割引、侵蝕の細分、JP端数、再習得、武器装備、発見段階、UIと既存の物語・世界への接続を実装対象に含む。新しい章や短い版へ置換しない。

## 所有と呼出し

- `GameSession` が通常の新規開始、装着・転職・武器・専心の結び付け、探索知識、報酬確定、保存を所有する。
- `BattleState` が予約・実行・勝敗を所有する。`EncounterEffects` はその戦闘の準備、付与、封緘、護衛、場、局面、反応回数と知識を保持する。別の戦闘エンジンへ切り替える方式は採らない。
- `IntegratedProgression` はEXP・再習得・侵蝕端数・JP端数・報酬分類と検証を所有する。UIで数値を直接書き換えない。
- `integrated_preview` は同じコスト・効果計算を読み取り専用で使い、未発見の敵規則は伏せる。`bind_focus` と `equip_weapon` は戦闘外だけで成立する。
- 比較した別案は、既存戦闘と新戦闘を別クラスで二重実装する構成。通常防御・予測・保存の二重管理になるため採らない。

## 暫定仕様

- 新規ゲームは保存形式2。旧形式1は旧セーブとして検証し、明示的な更新で新形式へ移す。テストの有無・シード・コマンド名でルールを切り替えない。旧保存の再現と新規開始の検査を別に持つ。
- 侵蝕は整数部0〜100と小数1桁の端数で保持し、新規ルールの戦闘加算は0.2、専用技実使用は0.1。90到達履歴は永続、祠は90未満だけ。旧整数値を10分の1へ誤読しない。
- JP半減の端数は人物×職業で保持。祠は現在保有する魔物専用技を消し、再習得の必要量を独立管理する。マスター特性は職IDごとに一度だけ。
- 新しい習得基準は既存2技を8/24JP、新技を60/96JP、上級職の追加技を144JP。マスターは通常120／既存上級4職180。旧技を削除せず、全20職に配分する。
- EXPはレベル1〜30、次のレベルに80＋20×現在レベル差のEXP。各レベルHP＋2、2レベルごとMP＋1を暫定値とする。攻撃値を自動で増やし続ける構成にはしない。勝利時のみ全参加者に付与し、上限変更で全回復・蘇生しない。
- 報酬は通常20EXP/1JP、課題5EXP/4JP、ボス40EXP/12JPを基準に、既存の実際の遭遇へ分類する。任意稼ぎを必須にしないことを経路検査する。
- 得意割引は元MP4以上かつ得意タグ一致で−1、その後に形態の有料技コスト加算。元MP0は0のまま。MP・対象・使用制限を実行時にも再検査する。
- 専心は装着中の攻撃技1つに結び付け、準備の次の本人行動機会だけ有効。増幅とは加算。過負荷は専心と併用不可。同系統の付与は重複拒否。
- 付与の期限は付与ラウンドの終了を1回目として2回目の終了まで。使った攻撃1行動で消費。過負荷後は次の本人の機会に攻撃不可、非攻撃は選べる。
- 封緘は個体共有3段階。充填開始前の加算で中断可能。成立ラウンドとその後2ラウンドは防御0。1個体1戦1回。未達は最後の加算後2ラウンドの終了時に消える。
- 武器は既存素材を使うデータ装備。1人1本、二刀流能力の装着中だけ2本。各武器の値を使い、4連撃は各武器4打。装着・持替は戦闘外だけ。
- フィールドは1ラウンド予告して2ラウンド有効、最大1。敵味方の射撃を半減し、維持装置の破壊で解除。装置は新しい31番目の敵種に数えない。
- 同一戦闘の局面は資源・付与・過負荷を保持して切り替える。単にHPを回復させて戦闘時間を増やさない。既存の補給可能な連戦の波と区別する。
- 反撃は防御側1人につき相手1行動へ1回、反撃への再反撃0。追加効果は行動×対象1回、還元は支払MP以下かつ2以下。全効果の待ち行列解決後に勝敗判定。同時全滅は全滅とする。

## 実装時に具体化した点

- 護衛は未使用なら次の単体物理攻撃まで残る。魔法・全体攻撃では消費せず、担当者の戦闘不能で解除する。
- 爪の連撃は身体能力であり二刀流の対象外。武器技の4連撃は2本で8打。武器は共有の貸与目録で、同名武器の複数人利用を許す。有限在庫を装う個数表示はしない。
- 旧来の基礎技は共通技として元のMPを保持。追加技に得意タグを付け、全20職の得意と照合する。形態の有料技加算は共通技にも適用する。
- `data/integrated_campaign.json` に80話と49拠点の配分を明記。装甲調整器破壊・封緘完成は通路を開き、導電が有効な攻撃・残留解除は武器貸与を解放し、反射場の装置破壊は一度だけ回復薬2個を得る。単に技を予約・付与しただけでは解決と記録しない。
- 同じ区画へ戻った場合も解法・通路・貸与目録・補給取得は保存値から再現する。区画の構造や物語本文を再生成しない。残留反応の基礎被害は予告に表示する。
- 上級4職の噂・図鑑は開いて読んだ記録を保存。噂は町でのみ初取得でき、以後の再確認は場所を問わない。解放通知と転職可否は実際のマスター・侵蝕条件から決める。
- 対象が先に倒れた場合、既存の対象再選択規則を維持する。新たな適合対象がいない不発はMPも使用回数も増やさない。通常防御・偏向・護衛は先行処理する。

検査の区分と旧条件の保持は `integrated-validation-boundaries.md`。実行結果は個別の `docs/verification/integrated-*.json` に記録し、ここに未実施の全編検証や人間の評価を補完しない。
