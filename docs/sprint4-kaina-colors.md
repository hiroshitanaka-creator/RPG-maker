# カイナ8系統：明部と目の光の修正

依頼者が採用した形・動作を保ち、戦闘8シートの色だけを修正した。開始時の未コミット変更・未pushコミットは0件。比較元は `05dcae43ddff1bbf7fef22b41f52233cfe9b9a24`。

## 変更内容

- 戦闘用に既存のnatural.gplから20色を選択。初回の16色に、黄土色・淡い黄色など4色を加えた。実際の使用色は系統ごとに17〜20色。パレット本体と規約の上限は変更していない。
- 生成済みの動作原画から色を再取得し、暗い輪郭線を保って中間色と明部を持ち上げた。植物系は補正を強め、つるの明暗を出した。新しい画像生成はしていない。
- 96pxの各コマで目・花の中心の範囲を指定し、その中の暖色だけを調整した。口・爪・くちばしは発光の対象にしない。茶色を残して黄土色・淡い黄色へつなぎ、光点には今回の配色で最も明るい `#EEF6EB` を使用した。
- 72pxへの最近傍縮小で残る画素を光点として選ぶ。最初の追加検査で消える光点が見つかったため、実際の縮小結果から選ぶ処理へ修正して再検査した。
- 甲殻系の被弾コマは元の絵で閉眼しているため、その表情を維持し、光る目を描き足していない。
- 戦闘24コマの透明・不透明の形と位置は、採用済み版と完全一致。歩行素材、12職、残る3人、背景・音・字体など対象外の登録素材673件もバイト単位で一致した。
