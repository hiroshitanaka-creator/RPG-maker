# 魔物職の解放の分け方と4体の主

### 解放の分け方

魔物職8種類を、2つに分けて解放する。

1. **オアシスの村の祠で、ネルから4種類**：スライム系・獣系・植物系・甲殻系
   - 理由：「味方を強くする（スライム）・連続攻撃（獣）・回復（植物）・守り（甲殻）」の4つがそろい、最初の4種類だけでバランスの良い組み合わせが作れる
   - 植物系は、ネル自身が昔使った力。甲殻系は、洞窟の人物ガドが戻れなくなった姿の力
2. **倒さなくてもよい4体の主から、4種類**：不死系・鳥系・精霊系・竜系
   - 理由：「敵の動きを封じる（不死）・武器の攻撃（鳥）・魔法（精霊）・強力な連続攻撃（竜）」と、より特殊で強い力なので、寄り道をして強敵に勝ったごほうびにする

### 主（ぬし）

- 主は、旅の途中の寄り道の先に1体ずつ待っている、倒さなくてもよい強い魔物。物語の本筋の進行には必要ない。
- 主を倒すと、主の声が、その魔物職の力を差し出す。**受け取るかどうかを、プレイヤーが選ぶ**。受け取ると、その魔物職が解放される。
- 4体の主の居場所：

| 魔物職 | 主の居場所 |
| --- | --- |
| 不死系 | 第2地方の遺跡の、本筋から外れた奥の部屋 |
| 鳥系 | 第3地方の雪山の頂 |
| 精霊系 | 第3地方の凍った湖 |
| 竜系 | 後半、空飛ぶ船で行ける場所 |

- 主の正体：
  - 基本は、**力を守ってきた強い魔物が、自分を倒した相手を認めて、力を託す**。
  - ただし、**不死系の主（遺跡の奥）だけは、昔、魔物の力に深く進みすぎて戻れなくなった人の成れの果て**。倒されることで、自分の力を次の誰かに託せる。遺跡で「深く進んだ人を戻す方法はない」と知る物語と重なる場面にする。

### 主の呼び名の決め方

- 主は、**居場所で呼ぶ**（例：「○○の主」の○○に居場所を入れる）。何の系統の力をくれるかは、呼び名には入れない。
- 居場所の呼び方は、場所を作るときに決める。指揮役 Claude の仮の案（**決定ではない**）は、次のとおり：不死の主＝「書庫の主」、鳥の主＝「雪嶺の主」、精霊の主＝「氷湖の主」、竜の主＝「雲上の主」。
- **不死の主だけは、人だったころの本当の名前がある。** 戦っている間は居場所の呼び名で呼び、倒した後に、巻物か腕輪から本当の名前が分かる。

### 不死の主「ジーク」

- **本当の名前**：ジーク
- **過去**：人に戻る方法を、記録が文字を失うまで探し続けた学者の成れの果て。倒されて、やっと次の誰かに力を渡せる。
- 原画との関係：原画の、握りしめた巻物は、ジークが探し続けた記録。まわりを漂う紙片には、文字がない（記録が文字を失ったことを示す）。手首の腕輪は、人だったころの名残り。
- 物語との関係：遺跡で「深く進んだ人を戻す方法は、どこにもない」と知る物語と重なる。洞窟の人物ガドと同じく「戻る前に止まれなかった人」であり、ネル（そこで止めた人）と対になる。
