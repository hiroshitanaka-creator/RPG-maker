# 魔物職の解放の分け方と4体の主

### 解放の分け方

魔物職8種類を、2つに分けて解放する。

1. **オアシスの村の祠で、ネルから4種類**：スライム系・獣系・植物系・甲殻系
   - 理由：「味方を強くする（スライム）・連続攻撃（獣）・回復（植物）・守り（甲殻）」の4つがそろい、最初の4種類だけでバランスの良い組み合わせが作れる
   - 植物系は、ネル自身が昔使った力。甲殻系は、洞窟の人物ガドが戻れなくなった姿の力
2. **倒さなくてもよい4体の主から、4種類**：不死系・鳥系・精霊系・竜系
   - 理由：「敵の動きを封じる（不死）・武器の攻撃（鳥）・魔法（精霊）・強力な連続攻撃（竜）」と、より特殊で強い力なので、寄り道をして強敵に勝ったごほうびにする

### 主（ぬし）

- 主は、旅の途中の寄り道の先に1体ずつ待っている、倒さなくてもよい強い魔物。物語の本筋の進行には必要ない。
- 主を倒すと、主の声が、その魔物職の力を差し出す。**受け取るかどうかを、プレイヤーが選ぶ**。受け取ると、その魔物職が解放される。
- 4体の主の居場所：

| 魔物職 | 主の居場所 |
| --- | --- |
| 不死系 | 第2地方の遺跡の、本筋から外れた奥の部屋 |
| 鳥系 | 第3地方の雪山の頂 |
| 精霊系 | 第3地方の凍った湖 |
| 竜系 | 後半、空飛ぶ船で行ける場所 |

- 主の正体：
  - 基本は、**力を守ってきた強い魔物が、自分を倒した相手を認めて、力を託す**。
  - ただし、**不死系の主（遺跡の奥）だけは、昔、魔物の力に深く進みすぎて戻れなくなった人の成れの果て**。倒されることで、自分の力を次の誰かに託せる。遺跡で「深く進んだ人を戻す方法はない」と知る物語と重なる場面にする。

### 未決のまま残すこと

- 主の声の台詞、ネルが引用する古い記録の言葉、受け取る・受け取らないを選ぶ場面の具体的な流れ
- 受け取らなかった場合に、あとでもう一度受け取れるかどうか
- 主の名前、見た目、強さ
- 鳥・精霊・竜の主の居場所の、具体的な場所と行き方
- 解放の場面と主との戦いの、実装の時期
