# 祠の人物「ネル」

### 魔物職の解放の場面の組み立て

1. **場所**：第2地方のオアシスの村（仮）の祠。
2. **組み立て**：解放の場面では、魔物職の力の危険を正しく伝える。浅いうちは祠で清められることも伝える。そのうえで、「深く進みすぎた人を元に戻す方法が、古い遺跡にあるかもしれない」という希望を持って、主人公たちは遺跡へ向かう。遺跡では、「深く進んだ人を戻す方法は、どこにもない」と知る。
   - これは、ゲームの決まり（侵蝕が90未満なら祠で清められる。90を超えると人間の職業に戻れない）と、物語の決まり（侵蝕は元に戻らない。奇跡で戻す結末にはしない）に合わせた組み立てです。
3. **解放してくれる人**：祠の人物「ネル」。
4. **未決**：8種類の魔物職を、一度に解放するか、何回かに分けて解放するか。解放の場面の具体的な流れと台詞。

### ネル

- **名前**：ネル
- **役目**：オアシスの村の祠を守る女性。年齢は50代くらい。祠で、魔物の力についての古い記録を守りながら、村の泉と祠を世話している。主人公たちに魔物職の力の使い方と危険を教え、魔物職を解放する。「力を使いすぎた人を元に戻す方法が、古い遺跡にあるかもしれない」と伝え、主人公たちを遺跡へ向かわせる。
- **過去**：若いころ、植物系の魔物の力を使い、侵蝕が深く進み（ゲームの段階でいう「変異」まで）、そこで自分の意思で止めた人。人間の職業に戻れなくなる手前で止まった。洞窟の人物ガド（戻れなくなった人）と対になる人物。
- **人柄**：静かで温かい。苦労を知っているからこそ、相手を思いやれる。
- **話し方**（依頼者が決めた5つの決まり。言い換えずにそのまま記録する）：
  1. 短く、結論から言う。力の危険は隠さないが、責めない。
  2. 自分の過去は、聞かれた分だけ話す。「やめた」とは言わず、「そこで止めた」と言う。
  3. 相手の腕や目を見てから話す。使いすぎた人を、戻れなくなった人と決めつけない。
  4. 古い記録の言葉を、そのまま短く引用する。自分の意見と、記録の言葉を分けて話す。
  5. ガドのことは、殻や失敗とは呼ばない。「戻る前に止まれなかった人」と呼ぶ。
- **見た目**：
  - 白髪まじりの長い黒髪。頭には何もかぶらない。目元と頬に、小さな古い傷。
  - **顔に、斜めに走る緑の跡**と、**片方の目が緑**（侵蝕が顔まで進んだ跡）。
  - **片方の腕の、手首からひじにかけて、緑のつるが絡みついたような模様**。光っておらず、古い傷のように色あせたくすんだ緑（今は力を使っていない、昔の跡であることを示す。仲間の侵蝕の模様は光っているので、その違いで「今の侵蝕」と「昔の跡」を見分ける）。その腕の袖はひじまでまくっている。
  - 生成りと白の、ゆったりした長い衣。藍色の帯。肩から薄い藍色の布。革のサンダル。
  - 首に、木の葉の形の飾りのある数珠。
  - 片手に、泉の水を満たした石の器。もう片方の手に、ヤシの若い葉（水を振りかけて清めるための道具）。
