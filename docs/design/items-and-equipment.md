## 4. 装備

### 装備の枠

**決定（2026-10-04）**

- 人間の職業のとき：**武器・防具・装飾品×2**（合わせて4つ）
- 魔物職のとき：**装飾品×3**。武器と防具は装備できない
- 防具を替えても、見た目（衣装の絵）は変わらない

### 職業ごとに装備できる種類

**決定（2026-10-04）**

武器は5種類、防具は3段階に分ける。

- 武器の種類：**剣・刀・斧**／**拳**／**短剣**／**弓**／**杖**（刀は「剣・刀・斧」の種類に含める）
- 防具の段階：**重い**／**中くらい**／**軽い**。重い防具を装備できる職業は、中くらいと軽いも装備できる。中くらいを装備できる職業は、軽いも装備できる
- 装飾品は、全員が何でも装備できる

| 職業 | 武器 | 防具 |
| --- | --- | --- |
| 戦士 | 剣・刀・斧 | 重い |
| 騎士 | 剣・刀・斧 | 重い |
| 剣士 | 剣・刀・斧 | 中くらい |
| 武闘家 | 拳 | 軽い |
| 盗賊 | 短剣 | 中くらい |
| 狩人 | 弓 | 中くらい |
| 薬師 | 短剣 | 軽い |
| 吟遊詩人 | 短剣 | 軽い |
| 僧侶 | 杖 | 軽い |
| 魔法使い | 杖 | 軽い |
| 賢者 | 杖 | 軽い |
| 祈祷師 | 杖 | 軽い |

### 職業を変えたときの装備

**決定（2026-10-04）**

- 職業を変えたとき、武器と防具は、**持ち物（袋）の中で、新しい職業が装備できる、いちばん強いもの**を自動で装備する。
  - 「いちばん強い」は、武器は攻撃力、防具は防御力で比べる。同じ強さのものが複数あるときは、それまで装備していたものを優先する。
  - 比べる対象は、袋の中の物と、その人がそれまで装備していた物。ほかの仲間が装備している物は、対象にしない。
  - 自動で装備した後も、プレイヤーは自由に付け替えられる。
- 人間の職業から魔物職に変えたとき：武器と防具は袋に戻る。装飾品の1つ目と2つ目はそのまま。3つ目の枠は空になる。
- 魔物職から人間の職業に変えたとき：武器と防具は、上の「いちばん強いもの」を自動で装備する。装飾品の3つ目は、自動で袋に戻る。
- 装飾品は、自動では付け替えない（効果がそれぞれ違い、強さで比べられないため）。

### 装備と敵の強さの決まり

**決定（2026-10-04）**

- 新しい地方の店には、**3段階**の装備が並ぶ。
- その地方の普通の敵は、**2段目の装備で無理なく勝てる**強さにする。
- 主（倒さなくてもよい強敵）は、**3段目の装備と、上手な戦い方で勝てる**強さにする。
- 装備と敵の数値は、この決まりに合わせて Codex が作り、戦闘を自動で何度も試して確かめる。依頼者は、遊んでみて「強すぎる・弱すぎる」と感じたときに直してもらう。
