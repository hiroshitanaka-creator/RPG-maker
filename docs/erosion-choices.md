# 侵蝕度と不可逆になる操作

2026年9月19日。魔物職マスターによる魔物化という凍結条件を維持し、魔物専用技の実使用と侵蝕度の選択を接続した。

## 確定条件と調整案

企画書に記載された侵蝕度0〜100、30の兆候・60の変異・90の不可逆、人間職のJP半減、常時表示、祠の解除条件は既存資料に基づく。モンスター職のマスター時に魔物化する条件は、現在の凍結契約を優先する。

次は依頼者が数値・細則を確定したものではなく、本実装の調整案である。

| 項目 | 実装した調整案 |
|---|---|
| 魔物職での戦闘 | 戦闘終了時に+3。勝利・全滅の両方で加算する。 |
| 魔物専用技 | 実際の使用1回につき+1。攻撃回数ではなく技の使用回数で数える。 |
| 共通技 | 人間職でも習得できる技は、魔物専用技の加算対象に含めない。既存の解除時の分類と合わせる。 |
| 人間職で90へ到達 | 戦闘終了時、90へ到達させた技の元の魔物職へ移る。JPは戦闘時の職へ加算する。 |
| 未マスターの移行先 | 職業は移るが、魔物化のマスターフラグや能力補正を勝手に付けない。既にマスターしている移行先なら既存の転職規則に従う。 |
| 60到達時のJP | その戦闘の終了時に60以上なら、人間職のJPを半分にする。端数処理は従来どおり切り捨て。 |

上限は100。JP・侵蝕・職業変更は結果確定時に一度だけ保存状態へ反映する。戦闘中に外見や能力値を途中で切り替える方式は採用していない。

## プレイヤーに見える動作

- 装着技の説明に、魔物専用技の実使用で侵蝕が増えることを表示する。
- 戦闘中は、実使用した専用技を含む現在値を画面上部へ表示する。戦闘終了時の加算と予約技を含む見込み値も表示する。
- 編成画面に「平常・兆候・変異・不可逆」の段階と30/60/90の条件を表示する。
- 魔物職の戦闘加算で90に達する場合は、戦闘を開始する前に確認する。
- 予約した技が発動すると90に達する場合は、ターンを実行する前に確認する。HP・MP・ターン・所持品をまだ変更せず、人間職への復帰と祠での解除ができなくなることを説明する。
- 人間職から移る場合は、移行先の魔物職名も表示する。「やめる・選び直す」で操作を取り消せる。戦闘中の取消では行動予約を保持する。
- 同じ戦闘で同意したキャラクターについて、同じ境界の確認を繰り返さない。他の仲間が新たに90へ達する場合は確認対象になる。

見込みは予約技が発動する場合の値であり、実際の加算とは区別する。予約取消、先に敵が倒れた場合、MP不足などの不発では、技使用の侵蝕を加算しない。技の実行後に全滅した場合は実使用分を加算する。

## 検証

保護された受入テスト・契約・スキーマ・起動設定は変更していない。追加検査`tools/check_erosion_choices.gd`を実装前に実行し、10件の失敗と終了コード1を確認した。その後、以下を実際の戦闘・画面操作で検証して成功した。

- 魔物職の戦闘+3と、専用技1回+1の合算。
- 人間職での専用技使用、59→60でのJP半減、89→90での職業移行、99→100の上限。
- 共通技・予約取消・不発では専用技使用の加算がないこと。
- 技の実行後に全滅した場合の加算、JPを与えないこと、職業移行で復活しないこと。
- 戦闘開始前とターン実行前の確認、取消時の状態保持、同意後に一度だけ実行すること。
- 90到達後の復帰拒否、実ファイルへの保存・別インスタンスへの読み込みの完全一致。
- 凍結R-01〜R-08、および前回追加した3人・4人の育成・帰還・解除操作。
