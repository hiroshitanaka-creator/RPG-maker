**採否は依頼者が見た目を確かめて決める。main にはマージしない。**

試みの中心は、建物の中との違い2点の解決である。

## 計画（作業前に決めたこと）

1. **縮める倍率：15/16（0.9375）**。
   扉の幅は、原画（1536×1024px）の宿・武器屋・防具屋の扉の木枠の外幅を4倍に拡大して測った（35〜36px。他は34〜36px）。
   32px／35px＝0.914。ここに近く、かつ町全体が端数なしの 1440×960px（45×30マス）になる 15/16 を選んだ。
   縮小後の扉の暗い開口は 29〜37px（1マス前後）。縮小は最近傍のみ（出力の (x,y) は原画の ((2x+1)·16÷30, (2y+1)·16÷30) の1画素）。
2. **町全体の大きさ：45×30マス**（1440×960px）。旧外観は48×32マス。
3. **通行地図の作り方**：縮小後の絵に32pxの格子を重ね、「人物の足元（マスの下半分）が地面に乗るマスだけ歩ける」規則で作る。
   - 建物：旧部品用に原画から切り出してあった多角形（`tools/import_region2_port_assets.py` の `CUTS`）を縮小し、マスの下半分の35%以上を覆うマスを通れない。扉のマスと扉の前のマスだけ通れる。
   - 海：青い画素がマスの下半分の50%以上のマスを通れない。
   - 井戸・露店・ヤシの幹・サボテン・岩・遺跡の石柱と石壁・船体・桟橋の杭と木箱：矩形で手書き（`tools/region2_port_town_defs.py`）。

   - 入口から歩いて行けない飛び地は、自動で通れない扱いにする（絵の飾りとして）。
4. **「上の層」に切り出す部分**：下記「上の層の仕組み」の一覧。
5. **うまくいかなかった場合に今の港町へ戻す方法**：旧外観のデータを作る `tools/build_region2_port.py` は変更していない。

## 船（2026年10月3日の修正）

最初の版では、原画に描かれた船を背景に残していたため、出航しても船の絵が桟橋に残った。次のように直した。

- 背景から船（船体・帆柱・帆・綱）を消した。消した範囲は `tools/region2_port_town_defs.py` の `SHIP_POLY`（杭と係船柱は `SHIP_KEEP` などで残す）。
  埋めた画素はすべて**周りの船のない画素を1画素ずつそのまま写したもの**で、ぼかし・混ぜ合わせはしない。
  - 海（2026年10月3日に直した）：最初の版は、船のない海の1か所の塊を、船の領域全体へずらして写していた。そのため上と左の端がまっすぐな線で区切られ、波の並びが単調で、写し元の境目に薄い線が出た。
    今は、**船の画素と船の影だけ**を埋める（船のすきまから見えていた本物の海はそのまま残す。範囲は船の形に沿った不規則な形になる）。
    埋めかたは Ashikhmin の画素合成：埋める画素ごとに、すでに決まった周り7×7の海の画素と最もよく合う画素を、原画の海の中から候補（①すでに埋めた隣の写し元の隣＝波の並びを続ける、②船から離れた海の画素24個、③同じ高さの左側の海）から選び、その1画素をそのまま写す。
    比べる相手は海の画素だけ（板や杭の色に引きずられない）。明るさと波の向きが近い場所が画素ごとに選ばれるので、同じ並びのくり返しや、1か所の写し元の境目の線は出ない。
    船の影（船の外へはみ出した暗い灰青）も埋める。板（茶色）と杭と綱のそばは触らない。
  - 桟橋の縦板（斜めの渡し板・中央桟橋の縁）：中央桟橋の船のない縦板を鏡像に敷いた。
  - 長い桟橋の上の縁（船体の下に隠れていた部分）：長い桟橋の船のない横板を鏡像に敷いた。
  - 岸壁の板の側面（帆柱が横切っていた部分）：同じ側面の船のない部分を鏡像に敷いた。前の帆柱の先は、左隣の砂を写した。
- 写し元の座標は全画素について `docs/verification/region2-port-backdrop/ship-erase-source-map.png` に記録した（形式は `assets/source_records/region2-port-town-backdrop.json` の `ship_erase.encoding`）。
  `tools/check_region2_port_backdrop.py` が、消した画素のすべてが、記録した写し元の**1画素の色だけ**から決まっていることを確かめる。
- 上の層の帆柱の部品は外した。
- 船は第1地方と同じ動く船の絵（`assets/vehicles/owner_ship.png`、192×192px）を、足元のマス(30,22)で桟橋のすぐ西の水面に重ねる。船が着いている間だけ描き、出航すると消え、帰還の風で港に戻ると桟橋に戻る
  （描画条件は第1港と同じ：`first_region_view.gd`）。中央桟橋の乗り降りのマス(34,21)は、船の東隣。
- 消した部分の拡大（消す前・今回の修正前・今回の修正後の3つ）：[ship-erase-before-after.png](verification/region2-port-backdrop/ship-erase-before-after.png)。
- 動く船の絵が着いている間に、消した範囲が船の絵からはみ出して見えないか：消した55576画素のうち、船の絵の不透明画素で隠れるのは13925画素（25%）。残りは船の絵の外に見える海の画素で、周りの海と同じ原画の海の画素から写してあるので、はみ出しとしては見えない（[ship-scenes.png](verification/region2-port-backdrop/ship-scenes.png) の出航前の画面）。記録は `ship-erase-coverage.json`。実画面：[ship-scenes.png](verification/region2-port-backdrop/ship-scenes.png)。

## 上の層の仕組み

背景には建物・木・柱も全部描かれている。上の層は、**そのうち人物より手前に見えるべき画素だけを背景と同じ画素で切り出して並べた素材**で、描画時に人物と同じ足元の順（`bottom`）で重ねる。

- 各部品には「足元の行」（その物が通れなくしているマスの最も南の行の下端）を持たせる。人物の足元（`セル行+1`）がこれより奥（北）の間だけ、部品を人物より後に描く。
  部品の `bottom` は「足元の行 − 0.5」にしてあり、人物との同順位（描画順が不定になる）が起きない。
- 切り出す画素は、**人物が立てるマスに重なる部分だけ**：人物が立つマスの矩形（そのマス＋頭の16px）と物の画素の重なり、かつ人物が物の足元より奥にいるとき。
  これより多くを切り出すと、手前を歩く人物を隠してしまう。
- 物の足元の行は列ごとに決める（L字の建物で、凹んだ所を歩く人物を壁の奥と取り違えないため）。ヤシの葉のように足元の列がない列は、最も近い列の足元を使う。
- 物の画素：建物・井戸・露店は多角形、ヤシ・石柱・アーチは「外周から続く砂色を背景として除き、物の塊だけ」を取る、帆柱は矩形。
- 描画は `scripts/world/first_region_view.gd` に約10行を足しただけ（`overlays` を持つ地図だけが対象）。通行・会話・扉・保存の処理は変えていない。

切り出した物（`tools/region2_port_town_defs.py` の `OBJECTS` と建物）：

| 建物の屋根の縁など | 宿 inn、道具屋 item、武器屋 weapon、防具屋 armor、祠 shrine、home_a、home_b | 港務所 harbor は、奥を歩けるマスがないため部品なし |
| アーチ | 石のアーチ arch | 通路の上のアーチの輪 |
| 露店の日よけ | stall_red、stall_blue、stall_gold、stall_sand | |
| ヤシの葉と幹 | palm_nw、palm_arch、palm_inn、palm_west、palm_shrine_r、palm_armor、palm_stall、palm_sw1、palm_sw2、palm_home、palm_south、palm_south2 | palm_shrine_l は到達できない窪みの中のため部品なし |
| 石柱の上 | pillar_d、pillar_e、pillar_f、pillar_g | pillar_a〜c、tower_n、tower_ne は奥を歩けるマスがなく部品なし |

## 分かったこと・残る違い

- 船は動く船の絵で、背景から船を消してある（上の「船」）。消した水面は周りの海を写しただけなので、元の絵に比べて波の並びが少し単調で、写し元の境目にごくうすい線が見える所がある。
- 扉の位置と32pxの格子は一致しない。扉の中心が扉のマスの中心からずれる量（右が＋、マス）は、宿−0.06・武器屋＋0.08・祠−0.08・港務所−0.12・道具屋＋0.30・防具屋−0.34・home_b−0.34・home_a−0.50。home_a は格子の境目にある。
- サボテンも通れない扱いにした（依頼文の通れない一覧にない）。
- 北東の遺跡の窪み（祠の左の砂地）と、遺跡の石柱3本（祠の東）は、入口から歩いて行けないため通れない扱い（絵の飾り）。上の層の石柱は南西の4本だけ働く。
- 以前の保存で、旧外観の歩ける場所に立っていて新外観では歩けない場所の保存は、既存の仕組み（`FirstRegion.relocate_unwalkable`）で入口(4,4)の前へ置き直される。

## これからの町（オアシスの村など）に使う手順と注意

1. 原画を縮める倍率を決める：扉の木枠の外幅を測って 32px になる倍率に近く、かつ縦横が32の倍数になる倍率を選ぶ（今回は15/16で45×30マス）。
2. 色：`natural.gpl` に原画の大事な色がなければ AGENTS.md の規則（1回につき最大4色、末尾へ、記録）で追加する。1枚64色以内に収まらないときは、使用画素の少ない色から外す。
3. 通行地図：建物の多角形（旧部品用の切り抜き）と海の青画素で自動の下書きを作り、遺跡・岩・杭・小舟は矩形で手書きする。確認図を原画に重ねて1マスずつ見る。
4. 物ごとの「足元のマス」を定義し、上の層を自動で切り出す。まず確認図の赤紫の範囲を見る。
5. 扉の前のマス・乗り降りのマスは、絵の上で板や床の上にあるか確認する。樽・杭が入口に置かれている絵は、入口のマスだけ例外で通れるようにするか、原画の差し替えを依頼する。
6. 実画面の撮影で、奥と手前の人物の見え方を数える（本書の `capture_region2_port_backdrop.gd`）。
7. 注意：
   - 状態で見た目が変わる物（船・開く扉・宝箱・動く住人）は背景に描かない。原画に描かれている場合は、背景から外すか、描かれたままの前提にする。
   - 部品タイルの存在を確かめる既存の検査（「8棟の部品」）は成立しなくなる。新しい表現に合わせた検査（本書の `check_region2_port_backdrop.gd`）を用意する。
   - 町が大きいほど上の層の物の数が増える。物の定義（足元のマスと範囲）が手書きの主な作業になる。
   - 原画の人物（NPC）は背景に描かない。絵に人物が描かれているときは、その人物を除いた原画を依頼する。
