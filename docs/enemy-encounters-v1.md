# v1の敵30種と連戦

2026年9月19日。元企画の敵30種を、既存6章案の戦闘地点へ配置した。敵の名前・能力値・技・編成順は調整案。職業20種とアビリティ37種、第1章の敵5種の能力値・技は変更していない。

## 変更したゲームの動き

回復役は弱った敵側の仲間へ回復を使い、蘇生役は倒された敵を戻す。防御役は防御と攻撃を交互に選び、速攻役は弱った相手や魔力の高い相手を狙う。MPが足りなければ通常攻撃へ移る。新しい戦闘計算式を別に作らず、味方と同じ技・MP消費・対象判定を使う。

敵カードに次の行動と対象を表示する。予定は1ターンに一度だけ決めるため、表示の繰り返しや味方の行動の選び直しで乱数を進めない。予定した攻撃対象が先に倒れた場合は、従来のルールで生存者へ変更しログへ残す。

| 戦闘地点 | 追加5種 | 編成 |
|---|---|---|
| 第2章・旧水路 | 再生、冷晶、岩殻、癒し、熔体のスライム | 2体→2体→1体 |
| 第3章・旧教習所 | 幽翼、骨翼、響き、見張り、夜渡りのコウモリ | 2体→2体→1体 |
| 第4章・記録坑道 | 鉄殻、氷殻、補修、熔殻、古殻の番兵 | 2体→2体→1体 |
| 第6章・分け水門の操作台前 | 火走り、火守り、灯火、灰還りの骸獣、炉心の魔狼 | 2体→2体→1体 |
| 第6章・分け水門 | 川辺、守門、疾風、影毛、溶岩の荒獣 | 2体→2体→1体 |

第1章の5種＋上表の25種で30種。既存の本筋戦闘10地点のうち後半5地点を3戦ずつにして、必須戦闘は合計20戦になった。章数・回収8件・回収連鎖2本は維持する。

1戦ごとに勝利を確定し、町へ帰還・休息・転職・装着変更・保存ができる。同じ地点を調べると次の編成が始まる。3戦を倒してから、その地点の物語を進める。敵の定義元は`tools/enemy_roster.py`、実行時データは`data/catalog.json`、編成は`data/story_v1.json`に置く。

## 保存と画像

セーブの任意項目`story_battle`に`step`と`cleared`を保存する。敗北では戦数を増やさず、同じ勝利を二度確定してもJPを重複付与しない。最後の勝利後・会話前に保存した場合も、再戦せず会話から先へ進める。章進行の番号は変更していない。新項目がない従来セーブは0戦済みとして読み込む。

敵IDと素材IDを`sprite_id`で分け、素材台帳に登録された実在PNGだけを参照する。今回の提供画像から14点を使用し、元の5点と合わせ19通り。詳細は[画像取り込み記録](user-monsters-20260919.md)を参照する。

## 検証結果と限界

- `check_enemy_encounters.gd`: 30種すべての配置、回復・防御・蘇生の実効果とMP消費、予定表示を繰り返した時の再現性、途中帰還とセーブ往復、敗北からの再戦、最終勝利直後の保存、重複報酬の拒否を確認した。
- `check_story_campaign.gd`: 新規開始から3人・教習→応答で700マス・81ターン、4人・応答→教習で700マス・51ターン、両方とも8件回収と結末へ到達した。固定シード、固定の操作方針による自動プレイである。
- 3人の初回通し確認は終盤2戦目で全滅した。2体の攻撃が回復役より先に入るため、追加の自動プレイに「予定された致死攻撃には通常防御を選ぶ」を加えた。敵の能力値、シード、勝利条件、検査のassertは変更していない。連戦の各戦前に帰還・休息する。敵の難易度全体が妥当と確認したわけではない。
- Godotの実描画で[戦闘画面](verification/screens/enemy_intents.png)を取得し、提供素材・HP・行動予定・味方の操作ボタンを目視した。この画面検査は進行位置を指定した確認であり、全章の人間によるプレイではない。

```powershell
godot --headless --path . --script res://tools/check_enemy_encounters.gd
godot --headless --path . --script res://tools/check_story_campaign.gd
godot --headless --path . --script res://tools/check_story_campaign.gd -- --three-member-party --teaching-first
```

5〜6時間の内容量・実測、人間による難易度確認、各ダンジョンの探索内容、全職の組み合わせでのバランス確認は残る。敵を30種にしたことや戦数を増やしたことをv1完成の証拠にしない。
