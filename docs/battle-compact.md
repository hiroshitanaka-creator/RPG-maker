# 戦闘の隊列と敵詳細表示の修正

> この文書は途中案の記録。撮影検査の更新は後続の依頼で承認された。最終配置と画素検査は [指定座標に合わせた戦闘画面](battle-layout-exact.md) を参照。ここに残る「未適用」「承認後」は当時の状態を示す。

依頼者が採用した下端3窓、濃い青と白の色、技名の帯、行動者の前進を維持し、味方・敵の配置と敵情報の表示タイミングを変更した。

- 味方4人の72px枠は左上から（388,56）、（402,84）、（416,112）、（430,140）。横14pxずつで、右端の幅114pxへ集める。隊列の順に描き、下の人物が前に出る。足元の重なりは今回の依頼で許可された範囲とし、顔は隠さない。
- 行動者だけ30px左へ進む。カーソルと演出は同じ座標を参照する。
- 敵は素材実寸の75%で表示し、元の小・中・大・ボスの体格差を保つ。通常敵の表示枠が重ならない間隔で並べる。3体までは横方向へ配置し、中央を少し手前へ出す。4・5体は奥と手前の2段に分け、足元の高さ順に描く。今回の通常敵の配置は右端x=322以内で、前進中の味方からも離す。
- 通常の敵一覧は名前と生存数だけ。HPと行動予定は対象選択中、カーソルが指す敵の情報に切り替える。戻ると通常の一覧に戻る。同名の敵も別々に選択できる。
- 対象名は1列にし、長い名前が横へ切れないようにした。対象欄は高さ28pxのスクロール領域、下の操作欄はy=32からの固定領域に分け、重なりを解消した。
- 「表示をスキップ  Enter」は、青い地と白い枠を持つボタンにし、草地に文字だけが浮く状態を直した。

## 敵の縮小表示の実測

`tools/capture_enemy_scaling.gd` で、スライム・コウモリ・甲虫・狼・大型の獣・ボスの6種類を、本番と同じ描画方式で原寸と75%表示にした。`ENEMY_SCALING_PASS: cases=6 interpolation=0 nearest_mismatch=0`。原寸の画素不一致、縮小時の補間色、最近傍の画素選択不一致はいずれも0。最初の測定では素材IDと敵IDを取り違えたため失敗し、測定入力を正しい敵IDへ直して再実行した。

`verification/battle-compact/enemy-scaling/` に比較画像と `measurements.json` を保存する。左は原寸、右は75%表示。実ゲームと同じ2倍の画面倍率で撮影した。色のにじみはないが、非整数倍なので画素の間引きと線幅の不均一は残る。素材PNG自体は変更していない。
