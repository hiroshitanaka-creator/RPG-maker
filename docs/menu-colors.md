# メニューの色・枠・字体の統一

2026年10月1日。採用済みの転職画面の色を、`menu-style-preview.md` の対象一覧へ広げる作業。画面の作りの変更は今回行わない。

## 実装した範囲

- `scripts/ui/rpg_menu_colors.gd` に濃い青（#101C50）・白い枠と文字・Noto Sans JP・白い選択枠をまとめた。選べない項目は #9AA6C4 の薄い文字、スクロールバーは青い溝と明るいつまみ。
- 既存の画面を作った後に、その場のコントロールへ色と枠を適用する。StyleBoxの有効な余白を引き継ぎ、フォントサイズ、文言、項目順、使用可否、選択時の処理は変更しない。
- 選択欄を開いたリスト、メモ入力、補足説明の小窓、リスト内部のスクロールバーも対象。
- `game_root.gd` は対象メニューへだけ共通色を適用し、画面を作り直すときには元のテーマへ戻す。探索・戦闘・店の画面、旧本編の専用画面へ適用を広げない。タイトル・記録・図鑑の背景は同じ位置に青地と白枠を描く。
- `first_region_atlas.gd` はテーマで渡された背景の色と枠だけを描き、地形・現在地・説明・ボタンの位置は変えない。

## 今回実施しない変更

最初の21枚は、メニュー、保存通知、道具、地図、帰還の風の未選択と選択後、転職、開いた職業一覧、未解放職業、装備と技の装着、図鑑、機構、祠の確認、旧保存の引継ぎ、手帳、記録の読み返し、タイトル、試遊記録、評価の一覧、メモ入力、習得済みの帰還と乗船項目があるメニュー。未解放職業は従来どおり能力比較のために選択でき、実行できない転職ボタンを薄色にする。

通常到達保存は無編集コピーで使う。帰還の習得・乗船・祠の確認・旧保存の確認は表示用状態から開いており、通常プレイの到達を示すものではない。記録の読み返しは未体験の物語を見せないため本文を空にした表示用状態で、会話窓を撮影した。ゲームの本番文言は変更していない。22・23では記録のある手帳とその選択一覧を追加した。実際の手帳生成処理を通すが、物語の文章だけは撮影プロセス内のデータ複製で表示用の文章に置き換え、終了前に元へ戻す。原本のデータファイルは変更しない。

色統一時点では文言・コントロールの順番・矩形・使用可否・選択内容が一致した。後述の本文高さ修正後は、その3画面の本文高さから導出した配置だけを新しい基準にして照合する。試遊記録の経過時間だけは実行ごとに変わるため、具体案どおり文型を照合する。撮影の上限180秒を変更していない。

## 本文が見えない不具合の修正（2026年10月1日）

色統一時点で、一覧の12「機構の覚え書き」、14「旧保存の引継ぎ確認」、22「記録のある手帳」の本文は高さ0pxだった。依頼者の修正指示を受け、各RichTextLabelの最低高さだけを128pxにした。本番コードの変更は3行で、文言・項目順・操作は変更していない。長い本文に対する既存のスクロール機能も維持する。

| 画面 | 本文の矩形（x, y, 幅, 高さ／512×288基準） |
| --- | --- |
| 機構の覚え書き | (16, 38, 480, 0) → (16, 38, 480, 128) |
| 旧保存の引継ぎ確認 | (16, 38, 480, 0) → (16, 38, 480, 128) |
| 記録のある手帳・記録一覧展開 | (16, 62, 480, 0) → (16, 62, 480, 128) |

`check_menu_colors.py` の変更は、上表の本文を新しい基準にする部分だけ。既存の縦配置により親の高さと後続ボタンのy座標も128px増えるため、変更前の値と本文の高さ差から期待値を計算して厳密に照合する。本文内の不要になったスクロールバーは、変更前の本文量（14・98・70px）が128px以内である場合だけ消失を確認する。ほかの要素の大きさ・文言・順序・選択肢・使用可否、残るスクロールバーの条件は維持する。

本番描画を再撮影し、3画面の本文とボタンが窓内に収まり重ならないことを画像で確認した。照合は全23画面成功。手帳の物語本文は、従来どおり撮影時だけ表示確認用の文に置き換えている。全画面一覧も更新した。
