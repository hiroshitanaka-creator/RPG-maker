# メニューの色・枠・字体の統一

2026年10月1日。採用済みの転職画面の色を、`menu-style-preview.md` の対象一覧へ広げる作業。画面の作りの変更は今回行わない。

## 実装した範囲

- `scripts/ui/rpg_menu_colors.gd` に濃い青（#101C50）・白い枠と文字・Noto Sans JP・白い選択枠をまとめた。選べない項目は #9AA6C4 の薄い文字、スクロールバーは青い溝と明るいつまみ。
- 既存の画面を作った後に、その場のコントロールへ色と枠を適用する。StyleBoxの有効な余白を引き継ぎ、フォントサイズ、文言、項目順、使用可否、選択時の処理は変更しない。
- 選択欄を開いたリスト、メモ入力、補足説明の小窓、リスト内部のスクロールバーも対象。
- `game_root.gd` は対象メニューへだけ共通色を適用し、画面を作り直すときには元のテーマへ戻す。探索・戦闘・店の画面、旧本編の専用画面へ適用を広げない。タイトル・記録・図鑑の背景は同じ位置に青地と白枠を描く。
- `first_region_atlas.gd` はテーマで渡された背景の色と枠だけを描き、地形・現在地・説明・ボタンの位置は変えない。

変更前は `d5833db` の `game_root.gd` を無編集で読み込んだ。共通の画面部品と保存は変更後と同一。世界地図は、共通テーマを渡さない変更前では従来の描画分岐を使う。変更後の記録は、本番コードのハッシュと照合して古い撮影記録で合格させない。

21枚は、メニュー、保存通知、道具、地図、帰還の風の未選択と選択後、転職、開いた職業一覧、未解放職業、装備と技の装着、図鑑、機構、祠の確認、旧保存の引継ぎ、手帳、記録の読み返し、タイトル、試遊記録、評価の一覧、メモ入力、習得済みの帰還と乗船項目があるメニュー。未解放職業は従来どおり能力比較のために選択でき、実行できない転職ボタンを薄色にする。

通常到達保存は無編集コピーで使う。帰還の習得・乗船・祠の確認・旧保存の確認は表示用状態から開いており、通常プレイの到達を示すものではない。記録の読み返しは未体験の物語を見せないため本文を空にした表示用状態で、会話窓を撮影した。ゲームの本番文言は変更していない。

文言・コントロールの順番・矩形・使用可否・選択内容は一致。試遊記録の経過時間だけは実行ごとに変わるため、具体案どおり文型を照合する。撮影の上限180秒を変更していない。

## 今回確認した既存の表示問題

一覧の12「機構の覚え書き」と14「旧保存の引継ぎ確認」の本文は、変更前後とも高さ0pxだった。元のコードに文字はあるが、画面には表示されない。今回の色変更による欠落ではなく、矩形も前後で同一。依頼範囲が色・枠・字体だけなので、表示領域を広げる修正は行っていない。この問題は今回の検査で「読みやすさまで解決済み」とは扱わない。
