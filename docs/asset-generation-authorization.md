# 画像生成の許可範囲

## 追加承認: 人物別の魔物化外見

依頼者の「現在、『残作業の記録』に乗っている必要な画像は生成してください。」に基づき、[残作業の記録](remaining-v1-work.md)の人物別素材を生成する。対象は4人×8職の歩行32点と、既存pc_01不死系1点を除く戦闘31点。計63点。通常人物の4方向歩行・戦闘・魔物化の表示接続も今回の明示依頼に基づいて実装する。

生成は人物・職ごとに15コマの原画アトラスを作り、歩行12コマと戦闘3コマへ分割する。既存pc_01不死系戦闘シートは保持する。最終PNGは既存の64色パレット、16色以下、アルファ0/255、歩行96×192・戦闘144×48に合わせる。新しい職業・章・地形の生成許可としては扱わない。

以下はこの追加承認より前の許可と取り込みの履歴。

2026年9月19日。依頼者の画像生成の許可を次の2点として記録する。

> 1. 地形タイル2枚・敵5体の新規画像作成を許可する。
> 2. 右向きになっている「左向き歩行B」の1コマに限り、画像生成による修正を許可する。

この対象はコミット`7a4e6fe1c5499e250dfbaa82d9f17cb7578a52f5`で既に生成・登録済み。今回の指示を受けて重複生成は行っていない。今回の照合では対象8ファイルのSHA-256が生成記録と一致し、pc_01歩行シートの変更対象外11コマは、提供画像から切り出した輪郭のアルファと一致した。素材規約は変更せず、左右反転での補完もしない。

## 以前の生成物との区別

前回は「画像で足りないコマはcodexで生成して下さい。」を広く解釈し、pc_03・pc_04の歩行補完5コマ、4人分の戦闘12コマ、不死系魔物化3コマも生成・登録している。この履歴は[素材取り込み記録](art-import.md)と[生成記録](image-generation-prompts.json)に保持する。

これらの追加人物コマは、今回明示された2点の許可に含めない。最新の許可を追加人物コマの再生成、別方向の描き直し、別の戦闘・魔物化画像の作成へ拡大しない。

依頼者は登録済み画像の削除や差し戻しを指示していないため、今回は既存ファイルと履歴を保持する。この許可の記録によって追加人物コマのゲーム内表示接続を進めることもしない。登録済みの画像、素材台帳、ゲームコード、凍結契約・テスト・保護ファイルには変更を加えていない。

## その後に提供されたモンスター画像

依頼者から2枚の画像と「モンスター画像を作成しました。使えたら使って下さい。」を受領した。これは提供画像の利用許可であり、上記の新規画像生成の範囲を広げるものではない。

[取り込み記録](user-monsters-20260919.md)のとおり、Pythonによる加工で17点を追加登録し、14点を敵へ割り当てた。この追加作業では素材台帳と敵・表示コードを変更した。新たな画像生成、人物画像の変更、パレット変更、保護ファイルの変更は行っていない。
