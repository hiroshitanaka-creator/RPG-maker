## 以前の生成物との区別

前回は「画像で足りないコマはcodexで生成して下さい。」を広く解釈し、pc_03・pc_04の歩行補完5コマ、4人分の戦闘12コマ、不死系魔物化3コマも生成・登録している。この履歴は[素材取り込み記録](art-import.md)と[生成記録](image-generation-prompts.json)に保持する。

これらの追加人物コマは、今回明示された2点の許可に含めない。最新の許可を追加人物コマの再生成、別方向の描き直し、別の戦闘・魔物化画像の作成へ拡大しない。

依頼者は登録済み画像の削除や差し戻しを指示していないため、今回は既存ファイルと履歴を保持する。この許可の記録によって追加人物コマのゲーム内表示接続を進めることもしない。登録済みの画像、素材台帳、ゲームコード、凍結契約・テスト・保護ファイルには変更を加えていない。
