# スプリント6：原画到着前の航路・沿岸

## 範囲

第2地方を砂と遺跡の土地、第3地方を雪と火山の土地として仕様書・ロードマップに記録した。正式名称は未決で、「第2地方の沿岸（仮）」等を表示する。

今回は第1地方の港から第2地方への航路、浅瀬での乗降、砂地を歩く骨組みまで。港町の入口・外観・6部屋は未接続。IMG_1008の流用、魔物職の解放、第3地方の地形制作、飛行手段の追加は行っていない。港町の原画が届いたら目標画像と2〜3配置案を並べ、入り江を囲む案を推奨案の1つとして示して止まる。

## 実装

- 既存256×256世界の第2地方の範囲内に、砂の岸を追加した。第1地方の描画・地形JSONは変更せず、`SecondRegionCoast` が追加データを本番描画へ重ねる。航行範囲は世界座標[24,40]〜[183,119]、第2地方の浅瀬は船[155,109]・徒歩[156,109]、徒歩経路の確認地点は[168,99]。
- 地面は登録済みの `field_outdoor.png` の砂、岸は既存の土の接続タイル、海は `natural_water.png`。岸と経路の骨組みであり、港町や完成した遺跡の代用にはしない。既存のPNGと原本のバイトは変更していない。
- 第1地方の2つの乗降地点を保持し、第2地方の浅瀬を別のデータから追加する。海への徒歩侵入、陸への船の侵入、沖での下船は認めない。上陸後に再乗船できる。
- 海の新しい範囲へ、控えの青い水滴（仮）・赤びれの牙魚（仮）・赤爪ガニ（仮）を配置した。既存slime・bat・shell_guardの能力・技・弱点・報酬と同値にし、海の遭遇率0.025を維持した。第1地方の既存遭遇は変更しない。
- 帰還の風は従来のMP2と使用条件を保ち、第2地方の岸・海から訪問済みの第1地方へ帰還でき、船も帰港する。未実装の港町を訪問済みとして登録しない。
- 依頼者の追加決定により、地上には刺サボテン・サソリ・砂の虫を通常登録した。琥珀のしずくは登録しない。ミイラと石の翼像は遺跡の近くの候補として保管する。原画と最新の確認画像は [新しい敵3体の記録](sprint6-desert-monsters.md) を参照する。

## 承認を受けた敵総数の改訂

`GameSession` と `check_enemy_encounters.gd` の「30種ちょうど」は、最初に33種への承認を受け、その後の地上3種の登録指示と明示承認により旧30種＋海3種＋地上3種＝36種へ改訂した。旧30種の定義は追加検査で固定記録と比較する。系統別集計は旧本編の30種の「5系統×6種」を維持し、追加6種のIDを別に完全照合する。全36種の画像参照を確認し、回復・防御・蘇生・予定の再現性・連戦保存など、ほかの既存検査は維持する。
