# v1の残作業と今回の実装範囲

依頼: 5〜6時間の内容量と実測、人間による探索・報酬・難易度の確認、残る人物の歩行・戦闘・魔物化外見の接続。

## 開始時点の確認

- 既存6章案、町3、ダンジョン5、敵30種、回収8件は接続済み。内容量と5〜6時間の実測は未達。
- `pc_01`〜`pc_04`の歩行4方向×3コマと戦闘3コマは存在する。今回の明示依頼に基づきゲーム内表示へ接続する。
- 魔物化の専用戦闘シートは`pc_01`の不死系1点のみ。ほかの人物・職の専用シートと魔物化歩行シートは存在しない。
- 人間のプレイ記録・評価回答は未提出。自動実行を人間の試遊と表示しない。

## 未達を隠さず進める方法

1. 既存素材の歩行・戦闘・対応する魔物化外見を接続する。画像の欠落は素材台帳で追跡し、別の姿を完成品として割り当てない。
2. 操作時間・休止時間・章ごとの時間・戦闘と報酬を記録し、人間がゲーム内で探索・報酬・難易度を評価してJSONへ出力できるようにする。外部送信は行わない。
3. 既存6章と5ダンジョン内の探索区画・課題・戦闘を拡充する。300〜360分は設計上の目標として示し、実測の結果と分ける。時間稼ぎの待機や移動速度の低下は用いない。
4. 人間の新規開始から結末までの記録を受領して評価するまで、人間評価と5〜6時間達成は未検証のまま残す。

## 魔物化素材の不足と選択肢

対象職はスライム・獣・不死・鳥・植物・甲殻・精霊・竜の8種。

| 方式 | 必要素材 | 現在との差 |
|---|---|---|
| 職ごとに外見を共有 | 8職の歩行シート8点、戦闘シート8点。仲間の識別は名前と編成位置で保持する | 共通外見として採用できる全身歩行・戦闘セットは未作成 |
| 4人それぞれに外見を用意 | 歩行32点、戦闘32点 | 歩行32点と戦闘31点が不足。不死系pc_01の戦闘1点は存在する |

歩行は96×192、戦闘は144×48、共通64色内の16色以下、アルファ0/255。以前の画像生成許可は地形2枚・敵5体・指定歩行1コマだった。その後、依頼者から本記録の必要画像の生成を明示的に承認されたため、4人別の不足63点を生成する。共有方式へ縮小しない。

## 現在の実装

- 63シートの生成・規格変換・登録を実施し、台帳100画像の検査で不足0件を確認した。既存pc_01不死系戦闘シートは保持した。
- 通常の4人歩行、先頭の切替と保存、待機・攻撃・被弾、人物別8職の魔物化と解除後の表示を接続した。
- 既存5ダンジョン内に25区画・25課題・50戦を追加した。全体は70戦。300〜360分を目標とするが、330分という設計予算は未実測。
- 実時計の記録、章別集計、戦闘・装着・課題の履歴、人間の評価入力、JSON出力と集計を接続した。[試遊手順](playtest-guide.md)から起動できる。
- 人間の完走記録・評価回答をまだ受領していない。5〜6時間の確認、人間による探索・報酬・難易度の受入判断は未達として残す。
