## 未達を隠さず進める方法

1. 既存素材の歩行・戦闘・対応する魔物化外見を接続する。画像の欠落は素材台帳で追跡し、別の姿を完成品として割り当てない。
2. 操作時間・休止時間・章ごとの時間・戦闘と報酬を記録し、人間がゲーム内で探索・報酬・難易度を評価してJSONへ出力できるようにする。外部送信は行わない。
3. 既存6章と5ダンジョン内の探索区画・課題・戦闘を拡充する。300〜360分は設計上の目標として示し、実測の結果と分ける。時間稼ぎの待機や移動速度の低下は用いない。
4. 人間の新規開始から結末までの記録を受領して評価するまで、人間評価と5〜6時間達成は未検証のまま残す。

| 方式 | 必要素材 | 現在との差 |
