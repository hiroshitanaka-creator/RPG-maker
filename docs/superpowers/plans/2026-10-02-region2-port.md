# 第2地方の港町・案Aの実装計画

実行手順：superpowers:executing-plans。2026年10月2日の依頼と、採用された docs/proposals/region2-port-layout.md を基準に、この作業内で順に実行する。

目的：案Aの港町外観、砂の町の住人10人、6室を通常の航行・徒歩・施設利用へ接続し、物語と後続原画の決定を文書へ保存する。

構成：既存FirstRegionの部屋データへbrine_portを追加し、描画は外観の部品層と室内のbackdropを使う。船・帰還は既存FirstRegionTravelへ第2地方の港を追加する。Godot4.7.2、512×288、32pxタイルを維持する。

## 制約

- 原画と添付物語原文はバイト単位で保持。素材台帳・切り出し範囲・変換記録を保存。
- 既存素材、パレット色の順序と値、保護ファイル、R-01〜R-08、既存検査の上限を変更しない。
- 防具屋は会話のみ。祠の石板は飾り。洞窟の出会い、オアシス、遺跡、世界の水際変更は今回実装しない。
- 住人は32×48・4方向3コマの96×192シート、16色以内、二値透過。原画にない向き・動作は画像生成で補い、取り込み後は決定論的に変換。
- 新規検査2本とCI登録は docs/proposals/region2-port-checks.md の承認後に行う。

## 特に確認する条件

1. 6室の台・棚に人物が埋まらず、客側から話せる。防具屋の立ち位置の選択を記録する。
2. 船で第2港へ到着、陸路で町へ再入場、帰還の風で戻る各場合で船と乗り場の対応が保たれる。
3. 新港を訪問していない旧保存を勝手に訪問済みにしない。第1地方の乗降2か所を維持する。
4. 歩けない保存位置を6室とも入口へ置き直せる。
5. 商人の手荷物・住人の方向・歩行コマが不正にならず、原画の識別色が残る。

## 進行記録

- 生成された漁師・商人の左歩行3コマ目は向きが右だったため、変換時に左へ反転する。旅人の横方向2行は順序が逆なので入れ替える。適用したフレームと変換を記録する。
- 6室は現行の新ゲームから未到達で、完成済みの変更前画面は存在しない。実装済みと誤解される比較は作らず、変更前の状態と変更後の原画・実画面を区別する。
- 旧本編の汎用brine_portの内容を上書きすると、今回の外観とは別の進行まで変わる。新ゲームのFirstRegionで読み取る場合に限って独立JSONを適用し、既存world/interiors.jsonとその再生成手順は保持した。
- 防具屋の店員は受付台右端の手前、展示の鎧と重ならない床に置いた。台の奥は床が狭いため使わない。部品を重ねた配置図で確認済み、本番撮影は追加検査の承認後。
- 既存検査の初回はWindowsのuser://ログ書込み権限で失敗。同じ条件を権限のある環境で再実行し、R-01〜R-08全件成功。条件と時間上限は不変。
- 素材検査が依頼者原本の従来保管経路を要求するため、既存の砂漠敵取り込みと同様に同一バイトの保管コピー・受領場所・受領日を記録し、検査器は変更せず1118件の素材検査が成功した。
