# 仲間の加入場面

リオネとハルドは実装済み。スイナは依頼者の承認により会話案のみを保存し、森の塔への実装・接続はスプリント5で行う。既存の人物背景に合わせ、リオネは見回り役、ハルドは手当て係、スイナは記録を大切にする人物として書く。

## リオネ（実装済み）

- リオネ：その荷物……カイナ、どこへ行くの？
- カイナ：ソルダ洞窟へ。中の様子を、自分の目で確かめたい。
- リオネ：なら、あたしも行く。村の見回りは済ませたし、道を確かめるのは得意だよ。
- カイナ：助かる。でも、一人で先へ走らないでくれ。
- リオネ：分かってるって。危ない道を見つけたら、ちゃんと戻って知らせる。二人で無事に帰ろう。
- 一行：リオネが仲間になった。

## ハルド（実装済み）

- ハルド：カイナ、少し手を貸してくれないか。この子の包帯を巻き直したい。端を押さえていてほしいんだ。
- カイナ：このあたりでいい？　きつくならないようにするよ。
- ハルド：そう、そのまま。引っ張らずに、ほどけないよう押さえていてくれ。
  - 通常の決定操作：**包帯の端を押さえる**
- 村の子：あ……今度は痛くない。
- ハルド：よし、巻けた。もう端を離して大丈夫だ。ゆっくり頼む。
  - 通常の決定操作：**合図に合わせて手を離す**
- 村の子：しっかりしてる！　二人とも、ありがとう。
- ハルド：助かったよ。片手ではうまく巻けなくてね。ところで、旅支度をしているのかい？
- カイナ：これからソルダ洞窟へ行く。リオネも一緒だ。
- ハルド：それなら、私も同行させてほしい。手当ては任せてくれ。ただし、無理をする前に戻ること。それも大事な備えだ。
- カイナ：分かった。危ないときは、遠慮なく止めてくれ。
- ハルド：約束だ。誰か一人が我慢している旅にはしない。さあ、出発しよう。
- 一行：ハルドが仲間になった。

ハルドの手伝いは受領→押さえる→巻き終わって離す→加入の状態で記録する。最後の操作をせずに加入を確定できず、村を出る前に3人になる。配達案は採用しない。

村の子に別途話しかけた場合：

- 手伝い前：包帯がほどけちゃって……。ハルドさんが巻き直してくれてるんだ。
- 手伝い後：もう大丈夫。二人とも、ありがとう！

## スイナ（会話案・未実装）

森の塔で出会う場面。塔固有の謎や物語の答えはここで決めず、本人が旅へ出る理由だけを描く。

- スイナ：待って。いま通った道、行き止まりはあった？
- カイナ：東の階段の先が崩れていた。そこから先は見ていない。
- スイナ：東の階段は通れない。その先は未確認……と。ありがとう。分からない所まで埋めてしまうと、次に来た人が困るから。
- リオネ：ずっと一人で調べてたの？　危なくない？
- スイナ：危ないわ。だから、確かめられた範囲しか書いていないの。でも、この塔だけでは分からないことが増えてきた。
- カイナ：俺たちと来ないか。先の土地でも、見たことを一緒に確かめてほしい。
- スイナ：ええ、同行させて。自分の目で見たことを記録したいし、あなたたちの話も確かめてみたい。
- ハルド：休む時間も記録に入れてくれると助かるね。
- スイナ：もちろん。無理をした記録も残すわよ。あとで「平気だった」と言っても消さないから。
- 一行：スイナが仲間になった。
