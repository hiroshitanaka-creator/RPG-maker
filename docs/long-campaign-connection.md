# 長編の本番接続の記録

以下は部分制作時点の履歴。現在は20連作80話を本番へ接続済み。最新の検査結果は [長編の実装記録](long-campaign-finish.md) を参照する。

2026年9月20日。全80話のうち2連作8話を制作した。全体は未完成で、通常の新規開始ではまだ長編を有効にしていない。この記録は最初の2連作と進行機構の検査であり、60時間の完成・人間の実測を示さない。

## 接続したこと

- 新規開始時の参加フラグと、第1章の後の既存イベントを通過した開始フラグを区別した。旧保存へ必須の長編を後付けしない。
- 既存の点検が済んだ地点で、引き受けられる依頼の一覧を開く。前提を満たす複数の連作から選べる。
- 既存の移動、会話、実戦闘、帰還・休息、保存を使い、追加区画を進む。章や大陸・職業は追加していない。
- 長編の選択は、両方とも進められる。選択した結果の会話だけを後の場面へ出し、選ばなかった結果を混ぜない。
- 選択に応じて、再訪時にも使える通路を開くか、補給を多く受け取る。結果のフラグ、通行判定、描画へ同じ状態を渡す。
- 進行状態は既存の`expedition`と`progress_flags`へ保存する。両方の選択を同時に成立させた不整合は読み込まず、現在の状態を保持する。
- 長編を始めた本編では、全80話が揃い完了するまで結末を確定しない。長編の完了状況を計測へ渡し、未完走の60時間を達成として記録しない。

## 保存の範囲

`progress_flags`内の`long_campaign_enrolled`、`long_campaign_started`、`journey_*_cleared`、`journey_choice_*`、`journey_passage_*`を、既存の全キー比較で保存対象に含める。新しいトップレベルの保存領域は増やしていない。

計測の文脈には`long_campaign_required`、`long_campaign_complete`、`long_missions_completed`を追加した。これらは実行時に進行フラグから作る情報であり、単独の自己申告で完了にはしない。
