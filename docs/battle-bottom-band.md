# 戦闘画面の下端3窓（2026年9月27日）

コマンド・敵一覧・味方の能力値を、画面下端の帯にまとめた。濃い青の地に白い枠と文字を使う。人物は72px表示、背景は512×288の原寸全体表示のままとし、素材と敵の座標は変更していない。

## 表示と操作

- 下端は左からコマンド（x=4、幅148）、敵一覧（x=156、幅108）、味方（x=268、幅240）。いずれもy=216、高さ68。
- 入力中だけコマンド窓を出す。演出中は敵一覧と味方の窓を残し、従来の「表示をスキップ  Enter」は空いた左下に置く。
- 同じ種類・同じ表示名の敵をまとめ、生存数が2以上なら名前の後に数を出す。個体別のHPと行動予定は、同じ窓を下へスクロールして読める。
- 既存のコマンド名と操作を維持する。技が多い場合と対象選択ではコマンド内をスクロールできる。
- 成立した技・魔法の名前を、演出開始時に上中央の帯へ0.35秒表示する。入力予約や不発では表示しない。技の消費・威力・行動順は変更しない。
- 味方4人の左上は（175,56）、（262,84）、（349,112）、（436,140）。3人のときは列を中央へ寄せる。行動者だけ12px左へ進み、次の行動では元へ戻る。戦闘不能の通知では前進させない。
- 入力対象・行動者の名前を黄色で示す。描画、カーソル、攻撃・回復の演出、ダメージ数字は共通の人物座標を参照する。

## 変更した検査

依頼者の承認に基づき、非保護の `tools/capture_battle_formation.gd` を今回の配置へ更新した。

- 窓の座標と人物の間隔を新しい値へ更新。演出中のコマンド非表示、下端への窓の集約、青地・白枠・行動者名の黄色を確認する。
- 隊列順、72px表示、人物矩形同士の非重複、被弾時の3pxの揺れを含む非重複、顔の非重複、窓と人物の非重複を残した。
- 対象選択・演出位置、実際のHP・MPと棒グラフ、既存コマンド、敵のHPと行動予定、同梱字体、背景原寸表示の確認を残した。
- 同種敵2体の見出しが1件になること、4人それぞれの前進中の座標・対象カーソル・演出、行動後の復帰、技名の帯を追加した。14背景の確認も維持する。
- 保護された検査・契約・CI設定は変更していない。
