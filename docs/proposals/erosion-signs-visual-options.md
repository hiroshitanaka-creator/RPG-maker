# 侵蝕の兆候の絵：依頼者向け3案

魔物化32姿の制作後に選ぶための案。まだ採用・実装していない。依頼者の原画は未受領。どの案も4人の顔・髪・職業衣装を残し、完成した魔物化の姿とは見分けられるようにする。

| 案 | 絵の内容 | 見え方・必要な原画 |
| --- | --- | --- |
| 1：目と手先の小さな変化（推奨） | 人間の姿を保ち、目の一部に小さな光、手先に数画素の異なる色を入れる。4人の特徴と職業衣装はそのまま。 | 仲間本人だと分かりやすく、魔物化前の兆候として区別しやすい。4人の顔・手の変化を示す設定画が基準になる。 |
| 2：腕・頬の細い模様 | 片腕と頬に細い模様を少数入れる。顔を覆う仮面にはせず、模様の明暗で変化を見せる。 | 72pxの戦闘で見つけやすい。歩行では細部を省いて読める印にする必要がある。模様の形を決める原画が必要。 |
| 3：一部だけ魔物化 | 人間の服と顔を残し、指先・耳・足先など一部に、対応する系統の特徴を出す。例として獣の爪、竜の小さな鱗など。 | 8系統とのつながりをはっきり示せる。一方、系統ごとの部分変化の原画が必要で、通常の職業衣装との組み合わせも確認する。 |

推奨は案1。仲間の顔と12職の衣装を見失わず、完成した魔物化との違いも明確にできる。原因や物語上の意味は、この案では決めない。

現行の侵蝕の発生条件・数値・解除条件は変えない。現在の表示は人間の姿かつ侵蝕30以上で兆候素材を使う。採用後、職業衣装を保って表示する方法と必要な原画の枚数を確認してから制作する。今回は既存の侵蝕素材と処理を変更しない。
