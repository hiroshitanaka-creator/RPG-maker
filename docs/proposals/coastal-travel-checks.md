# 船・帰還の風の検査と撮影の具体案

依頼者はMP2と習得・借用場所を決定済み。検査の追加・更新への回答は別に確認中。既存の保護ファイル・R-01〜R-08・時間上限は変更しない。

- 港町の配置検査・撮影検査を、新しい施設前・桟橋・停泊位置へ合わせる。全施設到達、海への徒歩侵入禁止、人物の90%以上の画素が見えること、町内の非戦闘、保存復元などの既存条件は維持する。
- 町の海面が桟橋を除いて30〜42%に収まること、桟橋が複数あり乗船地点へ歩けること、船原画のSHA-256が一致すること、船4方向の寸法・64色以内・二値透過・共通パレット所属を確認する。
- 通常の港町到達保存から、祠で帰還の風を教わり、荷受け所で船を借りる。会話前は未取得、会話終了で取得し、二重取得で船が増えないことを確認する。
- 桟橋で乗船し、海を歩行と同じ1セル150msで航行する。海岸の陸地へ進めないこと、港・浅瀬以外で降りられないこと、港と浅瀬で降りられることを確認する。
- 海の戦闘が既存の敵・背景で動作し、戦闘後と保存読込後も乗船状態・船の位置・向きが保たれることを確認する。
- 帰還の風では選んだ生存者だけMPを2消費し、訪問済みの村・城下町・港町の入口前へ戻る。船は港へ戻り、プレイヤーは徒歩になることを確認する。
- 未習得、未訪問、MP不足、戦闘不能、洞窟・塔・戦闘中は拒否し、MP・位置・船の状態を変えないことを人工状態の境界検査で確認する。実際の通常到達とは区別して記録する。
- 旧保存は従来どおり読み込めること、船・転移の追加状態も保存復元できること、飛行手段を利用できないことを確認する。

本番撮影：入り江と停泊船、乗船前、海を航行中、浅瀬での乗降、帰還の風の仲間・行き先選択、港町へ戻った直後、港の桟橋へ戻った船。全体図は配置データからの描画であることを明記し、実画面と混同しない。
