# 第2地方の港町：追加検査と本番撮影の具体案

2026年10月2日。案Aの実装を確かめるため、次の非保護ファイル2本を追加する。既存テスト・R-01〜R-08・保護ファイル・既存の時間上限は変更しない。

依頼者は本具体案どおりの2本の作成・実行とCI登録を承認した。船取得後保存を作る準備も同じ撮影スクリプトの `--prepare` で通常操作から行い、その保存を無編集で次の本番撮影へ渡す。各実行の180秒上限を維持する。結果と画像は `docs/region2-port.md` を参照する。

## 追加・実行する検査

1. `tools/check_region2_port.gd`（headless、180秒以内）：港町の8棟と6室の対応、入口から全施設・中央桟橋へ到達、海と壁・家具への侵入防止、店員への台越し会話、宿泊・道具購入・武器購入、防具屋は会話のみ、町内で戦闘なし、訪問記録と帰還の風MP2、船の乗降と第1地方との往復、場所・向き・所持品・仲間を含む保存復元、歩けない場所の旧保存を入口へ置き直すことを確認する。画像は台帳と既存の素材検査で寸法・色数・二値透過を確認する。人工的な境界状態を使う検査は通常到達とは区別して記録する。
2. `tools/capture_region2_port.gd`（通常描画、180秒以内）：従来の通常プレイから作った未編集の船取得後保存をコピーして開始し、方向キーと決定キーで航行・下船・港町へ入り、店・宿・港務所を歩く。町全体、入口、井戸広場、桟橋と帆船、6部屋、会話・買い物・宿泊・再乗船・保存再開を撮影する。到達途中の戦闘を通常の戦闘操作で処理し、テスト用の瞬間移動や戦闘無効化は使わない。原画との比較や6部屋の新設前後は別の画像組み立て用スクリプトで作る。

`.github/workflows/ci.yml` に1の実行を追加する。既存ジョブの上限25分・35分や、他のステップは維持する。2の画面撮影はローカルで実行する。

## 変更前の扱い

現在の第2地方の港町は、新ゲームの航路からまだ入れない。既存の汎用拠点データに部屋があっても、依頼された6室の完成画面は存在しない。変更前はその状態を明記して残し、6室が以前から存在したような画像は作らない。変更後は6室の実画面と、それぞれに使った依頼者原画を対応させる。

## 可逆性と承認範囲

追加2本とCIへの登録はGitで戻せる。本案は既存検査の書換えを含まない。既存検査の条件に触れることが判明した場合は実装を止め、別の具体案を示す。
