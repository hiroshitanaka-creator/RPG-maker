# 侵蝕の合成素材に限る色数上限の確認案

4人×12職へ、採用済みの明るい模様を同じ色で重ねるための確認記録。2026年9月29日、依頼者は案1を承認した。素材規約に「侵蝕の合成素材に限り、元の素材の上限に、発光色の1色分を加えてよい（戦闘21色・歩行17色まで）」と記録し、本番の台帳へ適用した。以下は判断時の2案を残したもの。

元の衣装を変更せず実際に合成したところ、41シートで現行上限を1色超えた。最大は戦闘21色・歩行17色。内訳は `docs/verification/erosion-costumes/color-limit-proposal.json`、スイナの僧侶の比較は `suina-walk-color-proposal.png`。

案1（推奨）：侵蝕の合成画像に限り、戦闘21色以内・歩行17色以内を認める。全人物・全職業共通の規則にし、元の衣装の戦闘20色・歩行16色、魔物化・敵・背景などの規則、共通パレット72色は維持する。元衣装の画素と人物ごとの発光色を両方保てる。承認後は素材規約と該当する合成画像の台帳だけを更新し、既存検査の他の条件は変えない。

案2：現行上限を保ち、上限に達する衣装では光の縁をその衣装に既にある色へ寄せる。衣装ごとに発光色の見え方が変わり、特にスイナの明るい紫を同じ色にそろえられない。
