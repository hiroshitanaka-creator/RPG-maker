# メニューの色統一：撮影と変更前後の照合案

2026年10月1日。依頼範囲は色・枠・字体のみ。既存テスト・保護ファイル・契約・時間上限は変更しない。

追加するファイルは次の2本。

- `tools/capture_menu_colors.gd`：本番の画面生成処理で対象一覧の全画面、選択欄の展開、選べない項目、スクロール後の表示を撮影し、各画面の文言・コントロールの順番・矩形・使用可否をJSONへ記録する。通常到達の保存は無編集で複写して使う。祠の確認や旧保存の引継ぎなど条件付き画面は表示用状態で開き、通常プレイによる到達とは区別する。記録の再読は未体験の物語を出さず、空の本文の表示用状態で窓を確認する。既存のゲーム用の保存は書き換えない。撮影1回の上限180秒。
- `tools/check_menu_colors.py`：変更前後の記録を照合し、文言・順番・矩形・使用可否が一致することを確認する。試遊記録の経過時間だけは値が変動するので、表示の文型を比較する。変更後の窓の青地・白枠・Noto Sans JP、選択枠と無効項目の区別、スクロールバーと選択リストの色を確認する。記録を作った本番コードのハッシュを照合し、古い記録を現在の検証結果として使わない。

出力先は `docs/verification/menu-colors/`。変更前と変更後は別に保存する。各画面の画像と、全画面を並べた一覧を作る。CIの既存ジョブはそのまま実行し、この追加照合はローカルで実行する。

色や枠の変更によって位置・大きさが変わった場合は、比較を緩めず実装側で従来の余白を保つ。変更前に色の条件が不成立であることと、変更後に成立することを確認する。

追加ファイルはGitで元に戻せる。保護された検査の変更は、この案に含まれない。
