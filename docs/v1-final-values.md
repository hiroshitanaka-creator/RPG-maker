# v1の確定設計値と職業修練

2026年9月25日。依頼者の「行動回数条件を採用して契約・実装・テストを改訂」「暫定設計値の最終確定を進める」に基づく設計決定。依頼者が数値を一つずつ指定した事実とは区別する。現在の数値をv1の初期設定として採用する。機械検査の成功を面白さ・理解・実際の60時間の証明にはしない。

## マスターの成立条件

各人物が、その職で得たJPと成功行動回数の両条件を満たした戦闘の勝利時にマスターする。魔物職は同じ時点で魔物化する。技の習得は従来どおりJPで進み、修練達成までマスター特性・魔物化を取得しない。回数は戦闘結果確定時に勝敗を問わず保存し、JPは勝利時のみ取得する。回数は必要数で上限にする。

予約・取消・不発・MP不足・戦闘不能による未実行は0回。連続攻撃や複数対象でも1行動につき最大1回。予測画面・再表示・反撃による追加打では加算しない。現在職の条件だけを計数し、転職・祠で履歴を消さない。戦闘結果の二重反映は拒否する。

盗賊10回・僧侶5回・獣系20回は元企画の指定を維持した。他職は10回または20回とする。通常職120JPまでの120回の通常勝利に比べて回数自体を低くし、行動の種類を選ぶ意味を作る。20回の攻撃、10回の連撃・射撃・回復・防御は無効行動の空打ちではなく、実際の効果を条件とする。防御は生存中の防御実行を数える。自然に達成できるかの人間評価は未実施。

獣系の威嚇は8JP・2MP。萎縮は付与ラウンドと次ラウンドの物理与ダメージを25%減らす。効果中の重ねがけは禁止。制御を使って修練できる入口をマスター前に用意し、4連撃を使っただけで状態異常を与えた扱いにはしない。

旧形式1/2の読込みだけではルールを更新しない。通常画面で確認して引き継ぐと、既存マスターをlegacy_mastersとして維持し、未記録の回数は0から始める。新規ゲームは最初から修練条件を使用する。新しい保存にはmastery_rules_version=1と人物ごとのcounts・legacy_mastersを保存し、項目欠落を旧保存と誤認しない。

## 戦闘・育成・保存の確定値

| 項目 | v1で採用する値 | 理由・根拠 |
|---|---|---|
| 職・人数・枠 | 20職、3〜4人、通常2→3枠、魔物化+1で最大4 | 既存の依頼条件を維持 |
| 技の習得 | 基本8/24JP、追加60/96JP、上級144JP、威嚇8JP | 20職への現在の配分を維持し、修練技がマスターを前提とする循環を避ける |
| EXP | 上限Lv30。必要EXP80+20×(現在Lv−1)。各LvでHP+2、2LvごとMP+1 | JPとの役割を分離。無制限の攻撃値上昇や無料蘇生を避ける |
| 報酬 | 通常20EXP/1JP、課題5EXP/4JP、ボス40EXP/12JP | 既存の敵・遭遇分類と学習順の検査を維持 |
| 侵蝕 | 魔物職の戦闘0.2、魔物専用技の実使用0.1。30/60/90、上限100 | 550戦の頻度別測定で0〜100と各境界を確認。人間の使用頻度を代表する分布とは扱わない |
| 祠 | 90未満で−30、魔物専用技を消去。再習得進捗は独立 | 取得履歴を残しながら代償を実際に適用。転職だけの復活を防ぐ |
| 得意MP割引 | 元MP4以上で一致タグがあれば−1、その後に形態加算。元MP0は0 | 表示・予約・実消費の一致を確認 |
| 専心・増幅・過負荷 | +100%、+50%、+100%。専心と過負荷は併用不可。過負荷後の本人の次機会は攻撃不可 | 準備・装着・MP・次行動の代償を分けて検証 |
| 偏向・護衛 | 選択側0.2倍／反対側1.5倍。護衛は単体物理1行動の全打を0.5倍で引受け | 予告に応じて選ぶ用途を維持。全体攻撃を無効にしない |
| 封緘 | 共有3段階、崩し1戦1回、防御0は成立時+後続2ラウンド | 充填への割込みと有効期限を固定 |
| 反射場 | 予告1ラウンド、有効2ラウンド、同時1場、装置HP120、射撃0.5倍 | 解除対象と待つ選択を残す |
| 連撃・反応 | 武器ごと4打、二刀流8打。反撃は相手1行動につき1回、再反撃0。MP還元は支払額以下かつ2以下 | 多段による無限反応・還元を防ぐ |
| 形態の補正 | data/integrated_rules.jsonのforms全8件を現値で採用 | 元の加算補正を保持して弱点と有料技コストを併記 |
| 通常保存 | 1MiB未満、保存・読込み各2秒未満 | 実際の全編4経路で確認する上限。履歴削除で達成しない |
| 高頻度履歴保存 | 72,000件、16MiB以下、保存・読込み各5秒以下 | 60時間×毎分20件の合成負荷。プレイ時間の実測とは別 |

## 受入・評価基準の確定

T01〜T14の数値・測定対象・方針は、従来の `provisional-thresholds-v1.md` に置いた条件を以下の範囲で正式採用する。旧文書の初回FAIL・未実施は履歴であり、現在の成否は該当する実行記録で判定する。条件の数値を下げて合格させない。

| ID | 確定基準 |
|---|---|
| T01/AC-01 | 指定6戦×3人/4人、各シード0〜999。各勝率40〜60%、全滅・上限到達は敗北、実行エラーは失敗 |
| T02/AC-02 | 同じ固定試行で10ターン以内の終了80%以上 |
| T03 | 上限30ターン、打切り0% |
| T04/T05 | 指定通常戦の勝率95%以上、味方の実行行動前の全滅0件 |
| T06 | 各設備の代替解法、全員人間3人/4人の到達を維持。修練マスターを全職必須にして主経路を封鎖しない |
| T07 | 指定区画の薬消費中央値1以下・90%点2以下、二重報酬0 |
| T08/T11 | 必須目標・地点の一致100%、到達不能・表示領域外・操作不能・必要情報欠落0 |
| T09 | Windows実描画の入力反映95%点100ms以下、最大200ms以下。初回読込みは別 |
| T10 | 接地差0px、空コマ0、歩行順0→1→0→2、状態と画像参照の不一致0 |
| T12/AC-03 | 全保存対象のキー・型・値・配列順序の不一致0 |
| T13 | 既存回収8件・2連鎖、長編46件を保持。先行回収・未来情報・二重報酬0 |
| T14/PT13 | 目標60時間、初見有効記録の受入幅54〜66時間。区分不明の放置0。現在の人間実測はNOT_RUN |

固定ACの初期値は `acceptance_battle_initial_states_v1.json` の凍結入力を維持する。今回の修練条件へ合わせて比較対象の能力値・技を差し替えない。新規修練の到達・失敗境界・保存は別の新規ゲーム検査で確認する。

主観評価はPLAYTEST_QUEUEのまま機械受入へ混ぜない。従来の初見5人中4人という基準と各質問の尺度をv1の改稿判断基準として採用する。これは小規模な観測計画の確定であり、効果の実証・統計的保証・回答の取得ではない。依頼者本人を必須の試遊者にしない。PT16〜PT21は定性的な観測を行い、説明のつまずき・選択理由・反復感を記録する。

## 改訂と検証記録

旧契約と変更した保護ファイルの原文は `verification/mastery-amendment-before/`、変更前後のハッシュは `verification/mastery-amendment-protected-changes.json`。テストのskip・assert削除・旧期待値の弱化は行わない。新しい前提を持つマスター済み境界入力と、通常開始からの実到達を明示して分ける。

保護フックがハッシュ台帳の更新を拒否したため、反映案を `verification/mastery-frozen-files-proposed.json` に用意した。実台帳への反映と一致確認までは、契約改訂手続き・CI完了とは扱わない。依頼者の改訂判断そのものは受領済み。
