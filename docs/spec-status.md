- 4人固定で開始し、仲間加入イベントは作らない。
- 人間職5・魔物職3・上級職4の全12職。上級職名はPhase 2で確定する。

- 戦闘と主要システムを作り、ダンジョン1本・敵5種で体験を判断してから残りの物量へ進む。

これは資料の整理であり、ゲームの実装・テスト結果ではない。
