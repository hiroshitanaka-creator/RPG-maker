# 最初の地方の実装記録

対象は体験仕様v2の村内開始から、洞窟のボスを倒して関所を通るまで。次の地方、船、転移呪文は今回の実装範囲に含めない。正式な地名・物語・呪文名は未決のまま。

## 実装した通常操作

「新しくはじめる」で主人公1人が村の家の中に立つ。方向キーで家を出て、村の2人に向き合ってEnterで会話すると、既存人物が1人ずつ加入する。加入済みの人物は元の位置に残らず、二重加入もしない。村には宿・道具屋・武器屋があり、回復、回復薬購入、補強剣購入を利用できる。

体験仕様の節目3より前なので、この開始経路では転職と技の装着は未解放。編成での状態確認・先頭変更・武器の持ち替えは利用できる。既存の3人・4人開始とその育成規則にはこの制限を加えていない。解放イベントは今回実装しない。

3人になると村出口から世界マップへ出られる。出口は入口の1セル外側で、外向きになる。村内では戦闘は発生しない。世界マップと洞窟では、成立した歩行から標準の乱数で遭遇を抽選する。ゲームの開始・位置・フラグを検査専用入力で操作する経路は設けていない。

洞窟は地下1階・地下2階の2層。階段は往復でき、宝箱は合計3個。一度開けた宝箱は再取得できない。ボスは既存の戦闘処理で倒し、勝利した時だけ通行証を得る。倒したボスは再出現しない。通行証なしでは関所セルへ入れず、取得後は確認の台詞を経て徒歩で通過する。

メニュー選択による拠点移動は使わず、New Gameから到達する画面に「世界地図へ」「本編へ」は表示しない。旧本編を動かす既存関数・データは保存している。保護テスト用の `GameSession.new_game(3/4)` と既存の `start_new_game(3/4)` は従来の人数・旧本編開始を維持し、プレイヤー向けボタンだけが `new_first_region()` を使う。

## 地形と仮名

座標は既存256×256マップ内のタイル座標。第1地方 `riverlands` 内の `x=28〜45, y=44〜59` に配置した。変更はこの区画内の99タイルだけで、既存49拠点の座標・地方区分は不変。村の東に洞窟、北に川と関所がある。周辺の山と川で行動範囲を制限する。

| ID | 表示名 | 配置 |
|---|---|---|
| `start_village` | はじまりの村（仮） | 入口 `(32,53)`、退出後 `(32,54)`・下向き。内部は家と村の2部屋 |
| `first_cave` | 近くの洞窟（仮） | 入口 `(40,53)`、退出後 `(40,54)`・下向き。地下1階・地下2階 |
| `first_gate` | 関所（仮） | 手前 `(35,49)`、門 `(35,48)`、向こう側 `(35,47)`。川は `y=48` |
| `first_boss` | 洞窟の番人（仮） | 地下2階の `(12,3)`。敵定義は `gate_beast` を再利用 |
| `gate_pass` | 通行証 | ボス勝利で1個取得。戦闘前の取得や自動配布は行わない |

## 保存と既存仕様

保存データへ `first_region`（待機中の仲間・所持金）と、`overworld` の向き・部屋・位置・ボス撃破・開封済み宝箱を追加した。旧保存の構造を必須の新形式へ置き換えていない。旧本編の保存は読み込めるが、新しい冒険の途中で旧本編へ入れ替える操作は拒否して現在の冒険を保持する。旧保存の職業マスター保持処理は変更していない。

戦闘前の自動保存と全滅復帰には既存の処理を使用する。通常セーブ後に移動してからロードすると、同じ場所・向き・仲間の全状態・所持品へ戻る。

## 検証と確認範囲

- 依頼者がJSON数値の型を修正・再固定した受入テストを使用。A01〜A14は全PASS、終了0。判定・件数・時間上限は編集していない。
- R-01〜R-08、素材108件、判定器回帰23テスト、保護ファイル26件の一致を確認。
- 既存49拠点・22戦・保存72回・移動9,194セルの検査と、旧画面222件の検査も成功。通過した旧検査を自動CIから外していない。
- 局所地形の追加後も61接続と61復路の通行検査は全PASS。加速なしの61経路の実時間測定も全PASS、対象4ファイルのハッシュ一致も確認。結果は `docs/verification/world-terrain-realtime.json`。
- 地形と内部データの生成結果は、実ファイルを上書きせずメモリ上で照合し、再現性を確認。
- 手動用 `.github/workflows/legacy-campaign.yml` は旧本編の3ジョブ定義をそのまま複写したもの。移動の条件に合う失敗を確認していないため、自動CIから移した検査は0件。手動ワークフロー自体の実行は未実施。

最初の範囲の約1時間、全体約60時間、人間の探索・報酬・難易度評価は未実測。自動操作の所要時間を人間のプレイ時間として扱わない。次の地方へは依頼者の画面確認と次の指示があるまで進まない。
