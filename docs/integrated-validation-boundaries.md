# 新仕様と旧検査の境界

2026年9月23日作成、9月25日改訂。新旧のPASSを合算して、新仕様の未検証箇所を埋めない。職別行動条件は依頼者の明示指示で採用し、R-02・R-04と関連テストを改訂した。詳細は `v1-final-values.md` と `mastery-actions-delivery.md`。

| 対象 | 新仕様との不一致 | 保持する検査と追加する検査 |
|---|---|---|
| R-01〜R-08 | 通常防御・形態加算は維持。JPだけのマスターは承認済み改訂の対象 | JPと成功行動回数の両条件を検査する。旧アサーションは保持し、共有マスター入力に実際の行動実行を追加。旧契約・テスト原文・ハッシュを保存する |
| AC-01/02 | 職データから毎回習得済み技とJPを組むと、新技追加で固定入力まで変わる | `d4b5bef` の実測記録から3人・4人の初期状態をそのまま独立JSONに保存。ハッシュを別検査で固定。シード・編成・所持技・装着・HP/MP・方針・勝率帯は維持 |
| 旧侵蝕＋3/＋1、旧習得費用 | 新形式は＋0.2/＋0.1、120/180JP。旧数値を新規ゲームの期待値にはできない | 既存5本の数値・アサーションを残し、明示した形式1の保存入力へ適用。`legacy_save_fixture.gd` は検査用の入力で、本番側は保存形式だけで判定。新規開始・実戦・境界・祠・UIは `check_integrated_progression.gd` と `check_integrated_ui.gd` で別に検査 |
| 全編・広域 | 従来の検査成功は新機構の接続証拠ではない | 新規開始から全80話へ進む `check_long_full.gd` は形式2を使う。既存の旧保存経路はその代用にしない |
| 保存 | 新規変数を比較対象から除くと往復一致が無意味になる | `save_state_comparison.gd` の列挙に育成・知識・解法・武器・取得済み手掛かりを追加。再帰比較のキー・型・値・配列順序検査は保持 |
| 戦術比較 | 旧ACの勝率帯は、新規6機構の全戦闘へ自動適用されない | 240JP/4800EXP・同じ4人・同じシード0〜99の3構成を比較。中盤枠解放だけは明示した比較用初期条件。勝率・ターン・残MPを記録。全勝でも「面白い」「適切」と判定しない |

旧互換へ区分する5本は `check_progression_paths.gd`、`check_erosion_choices.gd`、`check_exploration_devices.gd`、`check_party_playtest.gd`、`check_v1_finish.gd`。旧値を検査する条件文の削除、skip、期待値の上書きは行わない。新しい形式2の通常開始で旧数値を返す隠れた切替も設けない。

職別行動条件は2026年9月25日に依頼者が採用を選択した。仕様判断待ちは解消し、新規ルールへ実装した。旧保存の取得済みマスターと未記録の回数は区別する。保護台帳の反映はフックに拒否されており、`verification/mastery-frozen-files-proposed.json` を反映して一致確認するまでは改訂手続き全体を完了とは扱わない。

合計表示・保存・復帰の境界検査に明示配置するマスター済み状態には、採用条件を満たす修練進捗も設定する。この入力を実際に行動した証拠へ昇格させない。成功行動そのものは `test/unit/test_job_actions.gd` と `tools/check_integrated_mastery.gd`、JP注入のない獣系の習得・魔物化は `tools/check_integrated_progression.gd` で別に検査する。全編検査は通常開始・通常の職業変更と技習得だけを使用する。
