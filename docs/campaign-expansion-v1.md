# 内容拡充・人物表示・計測の接続

> 履歴資料: 以下の進捗・未達・暫定値は記録時点の状態です。現在の実装・受入・残作業は [現在地](current-status.md) を参照してください。

既存6章案の中で、5ダンジョンへ各5区画を追加した。計25区画・25課題・50戦。従来の20戦と合わせて本編は70戦になり、敵の種類は30種のまま。新しい章や大陸を増やしていない。

## 内容と時間

| 既存ダンジョン | 点検内容 | 本編への挿入位置 |
|---|---|---|
| 旧水路 | 流れの行き先、水位、荷重、濁り、応答の確認 | 第2章の水路再訪 |
| 地下回廊 | 換気、支柱、搬送、反響、休息所の備蓄 | 第2章、水路から次の町へ出る前 |
| 旧教習所 | 習得と装着、防御、回復役、枠、魔物化の選択 | 第3章の三枠の教習を終えた後 |
| 記録坑道 | 原本、索引、時刻不明、帰還、記録の照合 | 第4章の記録調査 |
| 分け水門 | 圧力、支え、備蓄、保守橋、工具回収 | 第6章の最終操作へ向かう途中 |

25区画は5種類の通路配置を共有する。各区画に調査記録、通路の戦闘、三択の操作課題、出口の戦闘、次の区画への移動がある。追加分は内部進行125手順。課題の情報は画面で読み返せる。誤答では先へ進まず、正答で回復薬1個を一度だけ得る。最初の記録地点ではHP・MPを整えられ、途中の町への帰還と装着の組み直しにも対応する。

配置・文面・報酬・編成は調整案。`tools/build_campaign_content.py`から`data/campaign_content_v1.json`を再生成できる。既存の8件の回収と2本の連鎖は維持した。装着教習の課題は本編の回収後へ置き、記録坑道で番人の音の技の意味や、終盤の引継ぎの答えを先に明かす文面は避けた。

設計予算は各章25・85・55・60・20・85分、合計330分。内訳は戦闘175分、読む時間40分、移動と課題70分、編成と回復45分という仮定である。これは5〜6時間を達成した実測値ではない。人間による記録がなく、内容量が十分かは未確認。自動操作の所要時間を人間の時間へ換算しない。

## 保存と進行

元の43進行番号を保ち、`content_revision`と`expedition`で点検の途中段階を保存する。`world.section`が区画、`expedition.origin`が戻り先、`solved`が確定した課題、`wave`が戦闘の勝利状態を持つ。間違った区画・解答済み一覧・戻り先の保存は拒否する。

新規開始では5点検を本編に含める。従来の保存に新項目がない場合は既存経路で再開し、進行を後戻りさせない。人間の所要時間確認は新規開始の内容版で行う。途中の帰還、保存、再開で課題報酬やJPを重複付与しない。

## 人物表示

4人の歩行を接続し、通ったマスを後続へ渡す。編成画面から先頭を選び、選択は保存される。戦闘画面には各人物の待機コマを置き、解決した戦闘ログのスナップショットに合わせて攻撃・被弾を再生する。表示をスキップしてもダメージや乱数を再計算しない。

魔物化は人物4人×職8種の歩行・戦闘に対応する。素材は新規63シートと既存pc_01不死系戦闘1シート。[生成台帳](monster-form-generation.json)に内蔵image_genで使ったプロンプト、原画名、参照、SHA-256を残す。[取込結果](verification/monster-form-import.json)は最終PNGのハッシュを含む。生成は32枚の15コマアトラスで行い、既存不死系を置き換えないため、その原画の新しい戦闘3コマは採用していない。

`tools/import_monster_forms.py`で透過を二値化し、コマを分離、最近傍縮小、接地合わせ、既存64色パレットへの16色以内の量子化を行う。左右反転は行わない。最終画像は`assets/characters/pc_01`〜`pc_04/forms/<職ID>/`に保存する。通常素材と既存の魔物化戦闘素材は保持する。

## 計測と検証の区別

[人間の試遊手順](playtest-guide.md)の起動方法、評価入力、JSON保存、集計を実装した。進行状態と計測は分け、時計を見るだけで進行フラグや装着状態が変わらないようにした。

- `check_party_playtest.gd`: 4人・3人の歩行、先頭保存、32種の外見参照、実戦闘の攻撃・被弾、実際のJPによる不死系への変化と解除、計測・回答・保存の検査。
- `check_campaign_boundaries.gd`: 全25区画の到達性、戦闘前の進行拒否、誤答、重複報酬の拒否、区画途中の帰還保存、従来保存の互換性。
- `check_campaign_content.gd`: 3人・4人、二つの再訪順で新規開始から5点検・8回収・結末まで通常の操作入口で通過する。課題の正答をデータから選ぶ自動検査であり、人間が理解したことの検証ではない。

追加の通し検査は歩行が700マスから1,675マス、戦闘が20戦から70戦へ増えた。試行で3人編成の実行は287秒だったため、CIの追加通し検査の上限を300秒から600秒へ変更した。凍結された8つのverifyの文字列・300秒の上限・テスト本体は変更していない。既存の敵連戦の単体検査は、追加の水路点検が済んだ前提を用意し、元の検査項目を維持する。

人間による完走、探索・報酬・難易度への実回答、300〜360分の確認は未実施。ソフトウェア検査のPASS、画像の目視、設計予算330分を、それらの代わりにしない。
