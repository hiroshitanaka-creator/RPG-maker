## 作業内容

1. 次の区切りで作る場所と、その順番の案を、2〜3案作ってください。どの案にも、オアシスの村と遺跡のダンジョンを、含めるか含めないかを明記してください。
2. 進行表の節目6「第2地方の島々／モンスター職の解放」と、節目7「第2地方のダンジョン／鍵」に、今の第2地方（港町・沿岸・オアシスの村・遺跡）をどう対応させるかを示してください。進行表と食い違う場合は、食い違いと、直す案を書いてください。
3. 魔物職の解放を、この区切りに含めるかどうかの案を示してください。含める場合は、物語のどの場面で、どのように解放するかの案も示してください。
4. 各場所の作り方を書いてください。
   - オアシスの村の外観と、遺跡のダンジョンの各階は、一枚絵の方法で作れるか。作れない、または難しい点があれば書いてください（ダンジョンは画面より広い、階段や穴の扱い、上の層が必要な物など）。
   - オアシスの村の建物の中4部屋は、手前の壁が高い新しい描き方です。今までの部屋の作り方から、何を変える必要があるかを書いてください。
5. 各場所で起きる物語の出来事の案を書いてください。名前や台詞の細部は決めず、出来事の流れだけにしてください。遺跡では、「治療の記録を探し、侵蝕が元に戻らないと知る」流れを入れてください。
6. 足りない原画（住人、敵、背景、絵など）の一覧を作ってください。依頼者が Grok や ChatGPT dot に頼めるように、何が何枚必要かを書いてください。
7. 依頼者が決める必要のある事項を、3つまでにまとめてください。それぞれに選択肢2〜3個と推奨案を付けてください。
