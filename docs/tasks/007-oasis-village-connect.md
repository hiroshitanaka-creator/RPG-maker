## 目的

依頼書 002 の案A（村の接続を先行）として、第2地方のオアシスの村（仮）を、世界マップから歩いて入り、村の中を歩き、4つの建物に出入りし、住人と話し、宿で休み、保存と再開ができる状態にする。

## 背景

- 002 の報告書（`docs/tasks/reports/002-sprint6-next-plan.md`）の案Aが、この作業の計画です。必ず読んでください。
- 依頼者の決定（2026-10-04）：
  - 村の施設を先に作り、祠での具体的な職業の解放の場面は後回しにする。
  - 港町の住人と商品を村に流用しない。新しい人物と品ぞろえは別に決める。
  - 町・村の外観は一枚絵で作る。建物の中は、手前の壁が高い描き方で作る。
- main には、村の外観と4部屋の背景・上層（004 で色を仕上げ、依頼者が見た目を採用済み）があります。手順は `docs/region2-village-backdrops.md` と `docs/region2-port-backdrop.md` にあります。
- 村の住人の原画は、依頼者が Grok で作った `assets/_incoming/owner-2026-10-04-grok-region3/region3-world-map-alt-a.png` です。**ファイル名は世界マップですが、中身はオアシスの村の住人6人です**（付録B の対応表を参照）。上の段の左から、泉の番人・ナツメヤシの農夫・宿のおかみ、下の段の左から、ラクダ飼い・村の長老・子どもです。

## 作業内容

1. 最新の main を取り込み、Godot の素材の取り込みを行い、`check_frozen_files.py` と R-01〜R-08 が成功することを確かめてください。失敗した場合は、作業を始めずに報告してください。
2. **世界マップからのつながり**：第2地方の沿岸から、徒歩でオアシスの村に行けるようにしてください。村の外観の左右の石の門から、世界マップに出入りできるようにしてください。村を世界マップのどこに置くかは、第2地方の世界マップの手本（`assets/_incoming/owner-2026-10-01-region2-port/FD957627-8A7F-4F3A-B774-A0C15E046FB2.PNG`）の、オアシスの位置を参考に決めてください。
3. **村の外観**：main にある背景・上層を使い、村の中を歩けるようにしてください。通行地図と実際の通り抜け判定を、村の全マスで一致させてください。人物が屋根や木の葉の上に乗って見えないよう、上層の前後を確かめてください。
4. **建物の中4部屋**：宿屋・道具屋・武器屋・祠の4部屋に、外観のそれぞれの扉から出入りできるようにしてください。手前の壁が高い描き方なので、人物が壁の上に乗って見えたり、出入口で顔が消えたりしないよう、実際の画面で確かめてください。
   - 外観に描かれた扉のうち、部屋の原画がない4つの扉には、入れないようにしてください。入れない扉を調べたときの扱い（何も起きない、など）は、今のゲームにある仕組みの中から選び、報告書に書いてください。
5. **住人**：住人6人の原画から、これまでの住人と同じ形式（歩行 32×48px、4方向×3コマ、16色以内）の素材を作ってください。宿のおかみは宿屋の受付台の後ろに、ほかの5人は村の外観や建物の中の自然な場所に置いてください。道具屋・武器屋・祠の店員や世話役は、6人の中から、服装が合う人を選んでください。足りない場合は、置かずに報告書に書いてください。
6. **会話と施設の働き**：
   - 住人の会話は、仮の短い文にしてください。物語の大事な内容（治療の記録、侵蝕、神々、ガドなど）には触れないでください。会話の文は、報告書に一覧にしてください。
   - 宿屋は、今のゲームにある休む仕組み（全員の回復）を使ってください。料金は新しく決めないでください。
   - 祠は、今のゲームにある祠の仕組みを、条件を変えずに使ってください。職業の解放の場面は作らないでください。
   - 道具屋と武器屋は、品ぞろえが決まっていないので、建物・店員・会話までにしてください。物を売る仕組みは作らないでください。
7. **保存**：村の中と4部屋で保存・再開ができるようにしてください。歩けないマスの古い保存は、今ある置き直しの仕組みで入口に戻るか確かめてください。
8. **検査**：村の確認のための新しい検査と撮影の道具を足し、検査を CI に1ステップ足してください。確かめる項目は、世界マップとの出入り、全マスの通行の一致、4部屋の出入り、入れない4つの扉、住人との会話、宿で休むこと、保存と再開です。撮影は、テスト用の瞬間移動を使わず、普通に遊ぶ操作で行ってください。
9. **文書**：`docs/region2-village-backdrops.md` に、つないだ内容と、次の町に使うときの注意を書き足してください。自分で決めたこと（村の置き場所、住人の配置、入れない扉の扱いなど）は、`docs/decision-log.md` に書いてください。

## 守ること

- 職業の解放の場面、新しい道具や装備、物を売る仕組み、メダル、遺跡のダンジョンは作らないでください。
- 物語の大事な内容と、名前（地名・人物名）を決めないでください。地名は「オアシスの村（仮）」のように仮の呼び方にしてください。
- 依頼者の原画は1バイトも変えないでください。原画の大事な色が `natural.gpl` にない場合は、AGENTS.md の決まり（原画由来の色を4色まで追加）に従ってください。

- 第1地方と第2地方の港町の配置・素材は変えないでください。
