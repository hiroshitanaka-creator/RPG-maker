## 実装事項
- 040の型復元済み旧docから候補＋legacy_format_audit＋equipment_auditを返す。input/state/metrics/historyは不変。失敗candidateなし、理由と対象パスあり。

- 旧本編へfirst_regionを永続追加しない。equipment_state_viewのコピーだけに空reserveを補い、保存モードや進行は保持。元に存在する不正値を補完で隠さない。
- 数量：034Q1Aと035具体AAA、036採用追記/040数量表を固定。元の各枠・未装備解放品1、形式1P+2、不適合品返却、主武器/防具不足だけ補填、共通10の一回付与/未解放pending。
- 合法従前を維持。同職change_jobで最強化しない。安定ID生成と全人物配列順不変。数値/型/所有/数量を監査。
- 戦士既得masterにtwo_handedを1回追加、装着なし、未master追加なし。能力fixtureは明示contextへ渡し、現GameSessionの新保存受理とは区別する。未知能力を黙認しない。
