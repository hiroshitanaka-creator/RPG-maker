## 目的

第2地方の遺跡のダンジョンを作るための下準備をする。4つの階を一枚絵の背景で歩けるようにし、階段で4つの階を行き来できるようにし、遺跡の敵とボスと戦闘背景の素材を取り込む。

**この作業では、遺跡を物語の進行にはつなぎません。** 世界マップからの入口、鍵、治療の記録を調べる出来事、ボス戦の勝ち負けによる進行、通常の遭遇の有効化は、作りません。それらは、依頼者が魔物職の解放の場面と遺跡の物語の出来事を決めた後に、別の依頼書で行います。

## 作業内容

1. 最新の main を取り込み、Godot の素材の取り込みを行い、`check_frozen_files.py` と R-01〜R-08 が成功することを確かめてください。失敗した場合は、作業を始めずに報告してください。
2. **階の順番と階段のつながりを決める**：4枚の原画の階段の位置を確かめ、1階 → 2階 → 3階 → 最下層の順に、上り階段と下り階段がつながるように決めてください。原画の階段の数や位置が、この順番と合わない場合は、どう対応したかを報告書に書いてください。原画を描き直したり、加工したりしないでください。
3. **4つの階の背景**：一枚絵の方法で、4つの階それぞれを、背景・見えない通行地図・上層（柱・石像・壁の上の部分など、人物より手前に見えるべき部分）にしてください。
   - 縮める倍率は、通路や階段の幅を測り、人物（歩行 32×48px）と自然に合う倍率を、階ごとに決めてください。村の倍率をそのまま使わないでください。
   - 画面より広いので、主人公が歩くと画面が動くようにしてください。1枚の絵を画面に押し込むような極端な縮小はしないでください。
   - 1階の右の部屋の「床の穴」は、通れない場所として扱ってください。下の階へ落ちる仕組みは作らないでください。
   - 宝箱を置けそうな行き止まりの場所は、作業記録に一覧にしてください。宝箱そのものと中身は置かないでください。
4. **階段で行き来できるようにする**：4つの階を、階段で上り下りできるようにしてください。階段を使った直後の立ち位置と向きを決め、行き来を何度くり返しても、正しい場所に着くようにしてください。
5. **入口と出口**：1階の下の入口から外へ出る仕組みは、世界マップとのつながりがまだないので、作らないでください。入口のマスは、通れない場所にしておき、作業記録に「世界マップとつなぐ場所」として記録してください。
6. **敵とボスの素材**：
   - 遺跡の敵4体（砂岩の人形・呪われた甲虫・砂の霊・墓守の番犬）を、これまでの敵と同じ手順（切り抜き・縮小・減色・体格の区分）で取り込み、敵の台帳に追加してください。能力値は、既存の敵の決め方に合わせた仮の値にしてください。名前はすべて「（仮）」を付けてください。
   - ミイラと石の翼像は、取り込み済みの素材を使い、遺跡の敵として台帳の場所を「遺跡」にしてください。
   - 砂岩の巨像は、ボスの体格の区分で取り込み、台帳に追加してください。能力値は仮の値にしてください。
   - 遺跡の中の戦闘背景を、ほかの戦闘背景と同じ形式で取り込んでください。
   - 通常の遭遇とボス戦は、**有効にしないでください**。どの階でどの敵が出るかの案は、作業記録に書いてください。
   - 原画の色が `natural.gpl` にない場合は、AGENTS.md の決まり（原画由来の色を4色まで追加）に従ってください。
7. **保存**：遺跡の4つの階で保存・再開ができるようにしてください。歩けないマスの古い保存は、今ある置き直しの仕組みで、その階の階段の前に戻るようにしてください。
8. **検査**：遺跡の確認のための新しい検査と撮影の道具を足し、検査を CI に1ステップ足してください。確かめる項目は、4つの階の全マスの通行の一致、階段の行き来（くり返しても正しい場所に着く）、入口のマスが通れないこと、保存と再開、取り込んだ敵とボスの素材の形式です。検査は、**その時点だけ正しいこと**（この依頼書の担当の場所の外を変えていないこと、遭遇・ボス戦・入口が無効であることなど、後の依頼書で変わる予定のこと）と、**ずっと正しくあるべきこと**（4つの階の通行の一致、階段の行き来、保存と再開、素材の形式）を分けて作ってください。その時点だけ正しいことは、この依頼書の完成時のコミットに固定して確かめ、ずっと正しくあるべきことは、最新の版で確かめ続ける形にしてください（AGENTS.md の共通ルールに従う）。後の依頼書で遺跡を物語の進行につないだときに、この検査が正しい変更を「違反」と判定しないようにするためです。遺跡は物語の進行につながっていないので、撮影と検査は、遺跡の階を直接読み込む「確認用の状態」で行ってかまいません。その場合は、確認用の状態であることを、検査・撮影・報告書にはっきり書いてください。通常のゲームの保存やセーブデータは書き換えないでください。
9. **作業記録**：`docs/region2-ruins-groundwork.md` に、各階の倍率・大きさ・階段のつながり・上層の一覧・宝箱を置けそうな場所・敵の配置の案・世界マップとつなぐ場所・これからの作業（物語の進行へのつなぎ方）を書いてください。自分で決めたことは、`docs/decision-log.md` に書いてください。
