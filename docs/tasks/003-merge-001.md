## 目的

001 の成果（伝言板の一式、依頼者の決定の反映、文書の食い違いの修正、「自走の許可」）を、main に入れる。

## 背景

- 指揮役（Claude）が、001 の報告書とブランチの中身を確かめました。内容は問題ありません。
- 001 のブランチは、main の `dad3fca` から作られています。その後、main に `7bb62ad`（依頼者の道具と装備の検討原本を保存）が入り、`docs/design/items-and-equipment.md` が**古い版**で追加されました。
- 001 のブランチにある `docs/design/items-and-equipment.md` が**新しい版**です。新しい版では、戦闘後に自然に治る状態異常が「眠りと沈黙」に決まっています（2026-10-03 依頼者決定）。古い版では、ここが「確認中」のままです。
- さらに、main に `f53dcb5`・`c743331`・`6384ee8`（オアシスの村の背景の土台など）が入り、`docs/current-status.md` にも、001 の案内と同じ位置に、村の背景の土台の完成記録が追記されました。
- そのため、001 のブランチを最新の main に取り込むと、次の2ファイルが衝突します（指揮役が `6384ee8` の時点で確かめた結果）。
  - `docs/design/items-and-equipment.md`（両方で追加）
  - `docs/current-status.md`（同じ位置への追記）
- 001 では、クラウドの環境から `api.github.com` に接続できず、GitHub の CI の結果を確かめられませんでした。依頼者は、Codex の環境設定で `api.github.com` への接続を許可する変更を公開します。公開されていない場合は、下の「CI を確かめられない場合」に従ってください。

## 作業内容

1. 最新の main を取り込み、Godot の素材の取り込み（`godot --headless --editor --import --quit`）を行ってください。
2. 001 のブランチに、最新の main を取り込んでください（merge でも rebase でも構いません。強制 push が必要になる rebase は使わないでください）。
3. 衝突は、次の方法で解決してください。
   - `docs/design/items-and-equipment.md`：**001 のブランチの版（新しい版）を採用**してください。新しい版の SHA-256 は `948615a73fecff7dae7aea2c0e29aa6497bb2c6c81735cee438582651235561f` です。解決後のファイルがこの値と一致することを確かめてください。
   - `docs/current-status.md`：**両方の記録を残して整理**してください（依頼者決定、2026-10-04）。001 の「最新の進み具合はロードマップと伝言板にある」という案内と、main に入った村の背景の土台の完成記録を、どちらも内容を変えずに残し、日付の順に並べてください。どちらかを消したり、言い換えたりしないでください。
4. main の `7bb62ad` で追加された `docs/design/README.md` は、そのまま残してください。
5. `check_frozen_files.py` と R-01〜R-08 を実行してください（R-01〜R-08 は `.scope-lock/spec.lock.json` の各 verify のコマンドを直接実行してください）。
6. ブランチを push し、GitHub の CI の全ジョブが成功することを確かめてください。
7. 「自走の許可」の5つの条件をすべて満たしたら、main にマージしてください。マージした後、main の CI の全ジョブが成功することを確かめてください。
8. `docs/tasks/001-status-and-decisions.md` の状態の行を「確認済み」に書き換えてください。この依頼書（003）を `docs/tasks/003-merge-001.md` として入れ、状態の行を「報告済み」にしてください。

## CI を確かめられない場合

`api.github.com` に接続できず、CI の結果を確かめられない場合は、main にマージしないでください。ブランチを push したところで止まり、報告書に「CI 未確認のため未マージ」と書いてください。依頼者が GitHub の画面で CI を確かめて、マージします。
