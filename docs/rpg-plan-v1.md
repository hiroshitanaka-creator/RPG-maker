# RPG企画書 v1 — 職業・魔物化システム

2026年9月18日

## 1. 概要

- ジャンル: コマンド式RPG。職業システムはドラゴンクエスト7を下敷きに、アビリティ装着はファイナルファンタジー5方式
- 1周の想定プレイ時間: 5〜6時間
- パーティ: 4人固定。開始時点で全員そろっている（仲間加入イベントは作らない）
- 対象リポジトリ: https://github.com/hiroshitanaka-creator/RPG-maker
- 設計の背骨: 「職業を選ぶ」「アビリティを組む」「魔物化するかを決める」の3点。この3つが面白くなければ、物量を足しても面白くならない

## 2. 職業構成（全12）

人間職5: 戦士 / 武闘家 / 僧侶 / 魔法使い / 盗賊

魔物職3: スライム系 / 獣系 / 不死系

上級職4（解放条件）:

| 上級職 | 解放条件 |
|---|---|
| 上級職A | 戦士 + 盗賊 |
| 上級職B | 僧侶 + 魔法使い |
| 上級職C | 武闘家 + 獣系 |
| 上級職D | 不死系 + 僧侶（侵蝕度60以上で解放される魔物上位職） |

上級職の解放条件は職業一覧に表示しない。町の噂と魔物図鑑の記述から推測させる。職業名はPhase 2で確定。

## 3. マスター条件と常時特性

JP累積に加えて、職ごとの実績条件を1つ課す。

- 盗賊: 盗み成功10回
- 僧侶: 蘇生5回
- 獣系: 状態異常を20回付与
- 他の職も同様に、その職らしい戦い方を要求する条件を1つ設定する

マスターすると常時特性が1つ永続化する。常時特性は装着枠を消費しない。

## 4. アビリティ装着枠

| 状態 | 枠数 |
|---|---|
| 開始時 | 2 |
| 中盤のイベント後 | 3 |
| 魔物化状態 | +1（最大4） |

枠が増える瞬間を中盤に1回置き、組み直しの機会を作る。

## 5. 侵蝕度システム（0〜100）

加算契機: 魔物職での戦闘、魔物アビリティの使用。

| 閾値 | 段階 | 内容 |
|---|---|---|
| 30 | 兆候 | 外見と戦闘時の台詞が変わる |
| 60 | 変異 | 人間職のJP獲得が半減。魔物上位職が解放 |
| 90 | 不可逆 | 人間職に戻れない |

- 侵蝕度は常時表示する。隠さない。見えたうえで踏み越える選択にしないと、ただの事故になる
- 低下手段: 特定の場所で −30。代償は習得済み魔物アビリティの全消去
- NPC反応の変化は全面分岐にせず、要所3箇所に限定する

## 6. v1で作らないもの

- 本能枠（自動発動するアビリティ）— AI制御が必要
- 万能職・すっぴん相当の職業 — 終盤に全職を統合してビルド選択を壊すため
- 職業の組み合わせによる連携技 — 余力ができたとき最初に足す候補として保留
- 侵蝕度によるNPC反応の全面分岐

## 7. 物量

町3 / ダンジョン5 / 敵30種。

魔物化の閾値は、この尺の中で最低1回は踏み越えられる値に設定する。

## 8. 制作順と判定ポイント

1. 戦闘とダメージ計算
2. 職業・アビリティのデータ表
3. 侵蝕度と分岐
4. ダンジョン1本 + 敵5種で通しプレイ ← 面白さの判定ポイント
5. 残りの物量

4の時点で手応えがなければ、物量を足しても変わらない。ここで設計に戻る。
