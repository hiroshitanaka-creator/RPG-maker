# 指定座標に合わせた戦闘画面

2026年9月27日。依頼者が示した `battle-layout-mock.png` と足元座標を反映した。従来の途中案は `battle-compact.md` に経緯として残す。

## 配置

- 味方の足元中央は順に（392,112）、（412,146）、（432,180）、（452,214）。96px素材を72pxで表示する。3人でも1〜3人目は同じ座標。上から描き、下の人を手前へ置く。行動者は30px左へ進む。
- 敵は素材実寸の75%。5体の見本はコウモリ（110,120）、火の精（215,134）、スライム（90,178）、甲虫（180,200）、スライム（270,186）。1〜4体は2026年9月28日の追加指定へ更新した。座標と大型の横補正は [敵の群れの配置と対象一覧](enemy-group-layout.md) を参照。足元が奥の敵から描く。
- 下端3窓の上端はy=223、高さ65px。左からコマンド・敵一覧・味方。文字はNoto Sans JPの10px以上を維持する。スクロール領域とターン操作欄を分け、対象選択では選んだ行へ表示を追従させる。
- 通常の敵一覧は名前と生存数だけ。対象選択中だけ、その個体のHPと行動予定を表示する。2026年9月28日の追加指定により、対象選択中は左窓のターン操作行を隠し、窓内全体を名前一覧へ使う。
- コマンドは演出中に消す。スキップ操作は青い背景と白い枠の中へ置く。技名の帯、行動者名の黄色、HP・MPの棒グラフは維持する。

通常ゲームの敵4体上限と出現編成は変えていない。5体画像は `tools/battle_five_enemy_preview.gd` による撮影専用入力で、本番の描画と共通戦闘処理を使用する。

## 頭と顔の保護範囲

採用済み4職×4人×3動作の元画像を拡大して確認し、髪・帽子・顔・顎を囲む矩形の組合せを動作ごとに固定した。上部を横一杯の帯だけで囲むと肩・腕・襟まで入るため、攻撃や被弾で低くなった顎は別の矩形で加えている。最終範囲は次のとおり。座標は96×96の各コマ内の `(x,y,幅,高さ)` で、複数の矩形は和集合を使い、透明画素だけを除く。

| 職業 | 待機 | 攻撃 | 被弾 |
| --- | --- | --- | --- |
| 戦士 | (0,0,96,48) | (0,0,96,48)＋(36,48,32,4) | (0,0,96,48)＋(32,48,28,6) |
| 武闘家 | (0,0,96,48) | 同左 | 同左 |
| 僧侶 | (0,0,96,48) | (0,0,96,52) | (0,0,96,52) |
| 魔法使い | (0,0,96,52) | (0,0,96,52)＋(40,52,30,8) | (0,0,96,54) |

特に魔法使いの攻撃姿勢は待機より顎が下がるため、y=52〜59の顎も保護する。範囲は画素検査の記録から確認図へそのまま出力し、図と検査で異なる範囲を使わない。

範囲を黄色枠で示した `verification/battle-layout-exact/head-regions.png` と、元画像のSHA-256を含む `head-regions.json` を保存する。追加8職の未制作素材について確認済みとは扱わない。

`tools/check_battle_head_pixels.gd` は実ゲームと同じ1024×576の描画で、次を1物理画素ずつ確かめる。

1. 本番画面と、同じ座標・動作・戦闘不能色で単独描画した各人物を比較し、保護範囲内の色が完全一致する。
2. 手前に描く人物の不透明画素と保護画素の交差が0である。同じ色の人物に隠れた場合も見逃さない。
3. 窓の範囲に入る保護画素が0である。
4. 意図的に1物理画素だけの遮蔽物を置くと、検査が不一致を検出する。

被弾の入力は敵の攻撃、戦闘不能の入力は倒れた本人の通知として、本番のイベント形式に合わせた。仲間同士が通常攻撃するような本番にない表示入力は使用しない。

単独描画の透明部分の判定は透過用の描画領域で行い、色の比較は本番と同じウィンドウで行う。異なる描画先で発生した戦闘不能色の変換差を、許容誤差で通すことはしていない。

攻撃・回復の図形と数字は味方より奥へ描き、顔の上へ色を重ねない。戦闘不能は不透明な暗色表示にし、背後が顔へ透けないようにした。対象カーソルは人物より手前に描き、顔の外側に置く。演出・数字・カーソルの座標は対象人物と共通で、前進や被弾時の揺れに追従する。

## 検査

撮影検査 `tools/capture_battle_formation.gd` は依頼者の承認に基づき更新した。旧来の人物枠の完全非重複を、上記の厳密な頭・顔の画素検査へ置き換えた。頭部検査の成功記録が現在の版と一致しない場合も失敗する。

敵同士・窓・前進した味方と敵の非重複、隊列順、指定座標、対象選択と演出位置の一致、72pxと75%表示、字体とHP・MP値、既存操作、14背景の原寸表示は維持する。窓の文字は、画面内・窓内への収まりと字体が必要とする行高を確認する。対象名は実際に全個体を選んで、スクロール内に見えることを確認する。

実行方法：

```powershell
. ./tools/prepare_scope_env.ps1
godot --path . --script res://tools/check_battle_head_pixels.gd
godot --path . --script res://tools/capture_battle_formation.gd -- --capture
godot --path . --script res://tools/capture_battle_bottom_band.gd
python tools/build_exact_battle_review.py
python3 D:/Codex/.codex/scope-lock/scripts/verify_cli.py --quiet .
python tools/check_frozen_files.py
python tools/validate_assets.py --strict
```

画素検査・撮影には画面を描画できる環境が必要。記録は `verification/battle-layout-exact/head-pixels.json` と `checks/checks.json`。R-01〜R-08、保護ファイル、CI設定は変更していない。
